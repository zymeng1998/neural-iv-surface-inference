## TL;DR

Phase 3 set out to beat the per-date **RBF interpolation baseline** on test
MAE by ≥ 5 %, *with the conditional neural model on its own* (RBF-as-prior
hybrids were reserved for Phase 4 — [ADR 0004](decisions/0004_phase3_accuracy_push_framing.md)).
Three independent levers were tried — coordinate representation (3A), a
cross-attention decoder (3B), and microstructure features (3C) — plus a
data-correction interlude (3X).

**The acceptance bar was NOT met by any variant.** On the corrected
single-valued **clean OTM** substrate (the operative verdict, per
[ADR 0006](decisions/0006_duplicate_coordinate_data_correction.md)), RBF
posts test MAE **0.00613** and the best neural head (ANP point) posts
**0.00987** — **+61 %** above RBF; the calibrated production predictor is
**+90 %**. The dirty-substrate result looked far closer (best ANP head only
**+2.7 %** over RBF), but 3X showed that closeness was a **call-put
duplicate-coordinate confound** that flattered the neural models; correcting
it *widened* RBF's lead rather than closing it. Feature expansion (3C
`micro_v1`) *worsened* test MAE in all three heads. The reliability layer
(calibrated coverage, abstention, tradability) holds, and the DeepSets→ANP
architecture ranking survives.

**Verdict: Phase 3 closes negative on accuracy.** RBF remains the production
accuracy baseline; the forward path is **Phase 4 = RBF-prior hybrid /
residual neural model** ([ADR 0009](decisions/0009_phase3_production_predictor_selection.md)).

## Scope Recap

- **W10 / 3A — coordinate-representation ablation.** Decoder-only retrain on
  the frozen 2D.7 encoder, Fourier features vs raw `(k, τ)`. Raw won; neither
  closed the gap to RBF. The bottleneck is architectural, not positional.
- **W11 / 3B — cross-attention decoder (ANP).** End-to-end DeepSets encoder +
  Attentive Neural Process decoder ([ADR 0005](decisions/0005_cross_attention_architecture_choice.md)),
  three heads (gaussian / quantile / point) + K=5 ensemble + the Phase 2D
  calibration / decision layer. Strongest conditional model produced; on the
  dirty substrate it narrowed the gap-to-RBF to +2.7 %.
- **W11.5 / 3X — data correction (gating interlude).** A duplicate-coordinate
  audit found 93.61 % of strict-table rows are call-put paired duplicates,
  invalidating the single-valued-function assumption both the neural model
  and RBF rely on. 3X rebuilt an OTM-restricted single-valued surface,
  re-audited (PASS 12/12), and restated the full model-family ladder on the
  matched clean benchmark.
- **W12 / 3C — feature & inductive-bias expansion.** Added the 9-dim
  `micro_v1` microstructure context ([ADR 0008](decisions/0008_microstructure_feature_set_freeze.md))
  to the ANP and retrained all three heads on OTM. Clean negative.

## Dirty-vs-Clean Restatement (why the gap widened)

The dirty substrate made the contest look close. `comparison_wide.csv` pairs
each family's dirty full-fold test MAE with its clean-OTM test MAE:

| Family / head | Dirty test MAE | OTM test MAE | dirty/otm ratio |
|---|---:|---:|---:|
| rbf (interp) | 0.0662 | 0.00613 | **10.80×** |
| anp_single · point | 0.06837 | 0.00987 | 6.93× |
| anp_calibrated · fused | 0.08135 | 0.01162 | 7.00× |
| deepsets_single · point | 0.07558 | 0.01752 | 4.31× |
| mlp · point | 0.09053 | 0.03006 | 3.01× |

RBF improved the *most* under correction (10.8×) because the dirty call-put
duplicates forced it to average two-valued targets at the same coordinate —
exactly where interpolation is penalised and an amortized neural model is not.
Removing that confound moved the best-ANP-head gap from **+2.7 % (dirty)** to
**+61 % (clean)**. Source for the dirty ANP numbers:
[`results/3/spy_phase1_random40_noiselow/3b_compare/comparison.csv`](../results/3/spy_phase1_random40_noiselow/3b_compare/comparison.csv);
narrative: [`docs/research/duplicate_coordinate_methodology_progression.md`](research/duplicate_coordinate_methodology_progression.md).

**Implication for the §5 "partial success" clause:** a dirty-only reading
would show the gap narrowing > 50 % (29 % → 2.7 %) and might qualify as
partial success. The 3X correction invalidates that reading — on the
well-posed substrate the gap *widened*. Phase 3 therefore does **not** qualify
as partial success on accuracy.

## What Changed vs Phase 2D

Phase 2D's calibrated conditional (DeepSets decoder) posted dirty test MAE
**0.08552** ([`results/2D/comparison_summary.csv`](../results/2D/comparison_summary.csv),
`conditional_calibrated`). Phase 3's best calibrated ANP posted dirty test MAE
**0.08135** ([`…/3b_anp/metrics_summary.csv`](../results/3/spy_phase1_random40_noiselow/3b_anp/metrics_summary.csv))
— a ~4.9 % relative improvement in the conditional family. But the Phase 2D
*interpolation* baseline (0.07297) already beat both, and on the clean
substrate RBF dominates by a wide margin. So Phase 3 advanced the neural
**architecture** without advancing the **production accuracy answer**.

## Verdict

**Phase 3 closes negative on accuracy: no pure conditional-neural variant
beats RBF on the well-posed substrate, and the gap is wide (+61 % best head).**
The reliability layer is intact and the DeepSets→ANP architecture story
survives, but the headline hypothesis — "a conditional neural model can beat
RBF on its own" — is **not** validated. This is recorded in
[ADR 0009](decisions/0009_phase3_production_predictor_selection.md): RBF stays
the production accuracy baseline; the calibrated ANP reliability layer is
retained as a complementary trust signal; the forward direction is **Phase 4 =
RBF-prior hybrid / residual neural model**.

## Open Questions / Phase 4 Framing

1. **Phase 4 = RBF-prior hybrid / residual neural.** Let RBF carry the local
   interpolation it already wins; have the neural model learn the residual
   (sparse wings / extreme maturities) plus the calibrated reliability +
   abstention layer RBF lacks. Deployment answer reserved by ADR 0004 / 0009 —
   not a retraction of the Phase 3 research question.
2. **`micro_v1` log-transform rescue** is reserved as an opt-in (ADR 0008
   Outcome) but not pursued — pure feature expansion already missed the bar.
3. **All-11-OTM-variant robustness study** remains deferred; every clean-OTM
   number here is scoped to the matched `random40_noiselow_otm` substrate only.
4. **Clean-OTM coverage runs conservative** (0.9295 on test, just outside the
   ±2 pp band on the over-covering side). A Phase 4 calibrator re-fit on the
   clean substrate could tighten it; not a Phase 3 blocker.
