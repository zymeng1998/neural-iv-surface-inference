## Purpose

Measure **prediction stability under perturbation of the observed set** — the
first half of W2. For a fixed surface, repeatedly re-mask which quotes are
treated as "observed", re-run the predictor, and quantify how much the prediction
at each query point moves across mask draws. High spread = a fragile, low-trust
region; low spread = stable. This is a model-agnostic reliability signal that
plugs into the same `Predictor` interface as W1 (2A.2) and feeds the W2 risk
flags (2B.4) and the W5 decision layer.

## Non-goals

- Do NOT retrain any model per mask. Scope to **inference-time** re-masking with
  predictors that need no retraining (interpolation). Train-time masking
  sensitivity for the MLP is deferred until a conditional model exists (2C).
- Do NOT derive risk flags or plot heatmaps — that is 2B.4.
- Do NOT build the end-to-end runner or write artifacts — that is 2B.5.
- Do NOT implement no-arbitrage checks — that is 2B.3.

## Implementation steps

1. Create `diagnostics/` subpackage. Implement
   `mask_resample(df_date, keep_fraction, n_draws, seed) -> list[mask arrays]`
   that draws `n_draws` random observed-subsets of the existing observed points
   (subsampling the observed set, never inventing observations).
2. Implement `masking_sensitivity(predictor, df_date, keep_fraction, n_draws,
   seed)`: for each draw, build a per-draw frame whose `observed` reflects the
   subset, call `predictor.predict`, collect predictions at all query points,
   and return a typed result with per-point mean, std (instability), and draw
   count. NaN-safe; documented behavior when a point is never queried.
3. Provide an aggregate `instability_summary(...)` (mean/median per-point std,
   optionally restricted to unobserved points).
4. Unit-test with synthetic surfaces and a deterministic stub predictor:
   identical predictions across draws → zero instability; predictor that keys
   off the mask → positive, reproducible instability; seed reproducibility;
   length/shape invariants.
