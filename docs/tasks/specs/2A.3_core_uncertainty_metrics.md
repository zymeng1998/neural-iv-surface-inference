## Purpose

Implement the core, model-agnostic uncertainty-evaluation metrics that score any
predictor's reliability outputs. Roadmap W1 requires: prediction-interval
coverage (empirical vs nominal), interval width, error-vs-uncertainty
correlation, confidence-bucket metrics (error stratified by confidence), and
high-confidence MAE. These are pure functions over `(y_true, y_pred,
uncertainty/interval)` arrays — the measurement foundation every downstream
reliability claim depends on. Abstention curves are deferred to 2A.4.

## Implementation steps

1. Implement pure functions, each taking numpy arrays and returning floats/dicts:
   - `interval_coverage(y_true, lower, upper) -> empirical coverage fraction`.
   - `mean_interval_width(lower, upper) -> float`.
   - `error_uncertainty_correlation(abs_error, uncertainty) -> {pearson, spearman}`.
   - `confidence_bucket_metrics(abs_error, confidence, n_buckets) -> per-bucket
     mean error + count` (error stratified by confidence quantile bucket).
   - `high_confidence_mae(abs_error, confidence, keep_fraction) -> MAE on the
     top-confidence retained subset`.
2. Handle NaN/empty inputs explicitly (return NaN with documented semantics);
   never silently drop.
3. Unit-test against synthetic data with analytically known answers:
   - Known-coverage Gaussian intervals → empirical coverage ≈ nominal.
   - Monotone error∝uncertainty → correlation ≈ 1.
   - Confidence buckets recover injected error ordering.
