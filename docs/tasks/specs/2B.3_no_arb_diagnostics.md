## Purpose

Quantify **structural validity** of a predicted surface — the second half of W2.
Implement the no-arbitrage diagnostic checks the roadmap names: monotonicity,
convexity (in strike), and calendar (term-structure) sanity, each producing
violation counts and a continuous severity score. These are *diagnostics, not
constraints*: we observe and measure violations now so that a later stage (W5 /
Phase 3) can decide whether to penalize them. Pure functions over a surface, so
they score any predictor's output identically.

## Definitions (document precisely in code)

- **Calendar (term-structure):** total implied variance `w(k, tau) = sigma^2 *
  tau` must be non-decreasing in `tau` at fixed log-moneyness `k`.
- **Monotonicity:** undiscounted call price non-increasing in strike (equiv.
  bounds on the smile's slope) — state the exact tested quantity.
- **Convexity:** call price convex in strike — tested via discrete second
  difference along the strike axis at fixed `tau`.

## Implementation steps

1. Implement per-check functions over a single-date surface, each returning a
   typed result with: violation mask (per evaluated pair/triple), violation
   count, violation rate, and a severity score (sum/mean of signed magnitude of
   the breached inequality):
   - `calendar_violations(df_date)`
   - `monotonicity_violations(df_date)`
   - `convexity_violations(df_date)`
2. Implement `no_arb_diagnostics(df_date) -> dict` aggregating all three
   (counts, rates, severities), with NaN-safe handling of axes too sparse to
   form a difference (documented).
3. Unit-test on **constructed** surfaces with known structure: an arbitrage-free
   smooth surface → ~zero violations; a deliberately injected calendar inversion
   / concavity / non-monotone smile → detected with correct counts and positive
   severity; sparse-axis edge cases.
