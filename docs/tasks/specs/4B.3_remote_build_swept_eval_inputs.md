## Purpose

Materialize, on the **full OTM substrate** (test split first; val if needed for
provenance parity), the swept evaluation inputs for every regime × rung: the
sparser observed context (from the 4B.2 harness) and the **per-rung RBF
prediction at the fixed query coordinates** (reusing the 3X.6 / 4A.3 RBF
machinery — RBF re-fit from the sparser context). Emit a finiteness +
MAE-sanity audit (RBF MAE should rise monotonically as the context thins —
the diagnostic's sanity floor). Mirrors 4A.3 (the residual-dataset build), but
swept across rungs. **CPU pre-compute; no model, no GPU.**

## Where this runs

**Remote (RunPod), CPU-only.** RBF re-fit over many (regime × rung) passes is
the cost driver — heavier than a config flag, lighter than GPU training.

## Dependencies

- 4B.2 `done` (sweep harness + rung definitions).
- 3X.6 / 4A.3 RBF machinery committed (the per-date RBF the rungs re-fit).

## Scope contract (atomic story)

- **One question:** what does RBF predict at the fixed query set as the
  observed context thins, per regime × rung, on the full OTM test split?
- **One artifact bundle:** swept RBF/context parquet on the Pod volume +
  `artifacts/runs/4B3/{manifest.json, rbf_sweep_stats.csv}` committed.
- **One acceptance check:** 0 non-finite; per-rung RBF MAE monotone
  non-decreasing as sparsity increases (sanity); dense rung reproduces the 4A
  RBF floor 0.006132.

   floor (provenance).
3. Commit manifest + `rbf_sweep_stats.csv`; append journal (run record) +
   data_lineage (the swept-input pipeline step).
