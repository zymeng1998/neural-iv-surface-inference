## Purpose

Phase-entry decomposition story for epic 2C (Phase 2 Workstream W3 — Conditional
Neural Surface Model). It pulls epic 2C into active work, breaks it into atomic
stories each sized for one focused session, writes a spec per story, and
registers them on the board at `backlog`. Mandatory first story of every epic
per the operating model §4 ("phase-entry decomposition").

W3 introduces the first genuinely useful neural architecture: one **conditional
on the observed sparse quotes**, not just on coordinates. The Phase 1 MLP is a
coordinate-regression model `(k, tau) -> sigma` that ignores the option chain on
a given date and underperforms the interpolation floor. W3 replaces this with:

```text
O_t           -> z_t                   (encode the observed chain into a latent state)
(k, tau, z_t) -> sigma_hat_t(k, tau)   (decode the surface at any coordinate)
```

The roadmap selects **Set Encoder + Coordinate Decoder** as the first baseline:
a permutation-invariant set encoder is the natural fit for sparse, irregular,
variable-cardinality observed quotes, and a coordinate decoder lets the model be
queried at arbitrary `(k, tau)`. More expressive variants (Conditional/Denoising
AE, Neural Process / ANP) are deferred unless this baseline proves insufficient.

## Story breakdown (the decomposition)

| Story | Scope | W3 element | Depends on |
|---|---|---|---|
| 2C.2 Date-grouped conditional dataset + collation | New PyTorch `Dataset` that groups benchmark rows **by date** into a context set `O_t` (the observed points, each carrying `(log_moneyness, tau, iv_input)`) plus query points `(k, tau)` with `iv_clean` targets. Variable-cardinality `collate_fn` that pads ragged context sets to a batch tensor + boolean padding mask. Distinct from the point-wise `IVSurfaceDataset`. | data layer for `O_t -> z_t` | existing `data/` layer |
| 2C.3 Set-encoder + coordinate-decoder architecture | `nn.Module` pair: a permutation-invariant **set encoder** (DeepSets-style per-element MLP → masked mean/sum pool → latent `z_t`) and a **coordinate decoder** MLP `(k, tau, z_t) -> sigma_hat` with softplus output. Pure module + shape/permutation-invariance tests; no training, no data I/O. | the W3 architecture | — |
| 2C.4 Conditional training loop + config | Train the encoder+decoder on benchmark datasets: masked loss on query points, checkpointing (best val), per-epoch logging, early stopping, seed control. Config at `configs/conditional.yaml`. Mirrors the existing `training/train.py` + `configs/baseline.yaml` conventions. | training the conditional model | 2C.2, 2C.3 |
| 2C.5 Predictor adapter + evaluation parity | Wrap the trained conditional model behind the `Predictor` interface (extend `eval/adapters.py`), run it through the **same** W1 uncertainty-eval and W2 diagnostics runners on the **same** benchmarks as the Phase 1 baselines; commit result artifacts + an experiment-journal entry comparing it to the interpolation floor and the MLP. | evaluation parity / evidence | 2C.4, 2A.2, 2B.5 |
