## Purpose

Re-establish the Phase 1 masked-MLP baseline (`(log_m, τ) → σ`, no
conditioning on the observed chain) on `random40_noiselow_otm` so the
clean baseline ladder is complete (Q1): **RBF → MLP → DeepSets → ANP**.
The MLP is intentionally limited; it anchors the bottom of the ladder
and shows the clean-data value of conditioning.

## Where this runs

**Remote (RunPod), GPU pod** — first GPU story, rented only after the
3X.5 audit gate passes and the operator reviews the RBF-on-OTM scale.

  `random40_noiselow_otm`, vs MLP-on-dirty?

  training_curve.csv, predictions_{val,test}.parquet}`.

  counts match query rows, manifest records dataset/config/seed/code
