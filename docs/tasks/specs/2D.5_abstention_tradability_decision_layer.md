## Purpose

Convert the W4 reliability signals (calibrated `confidence_score`,
`uncertainty_band` from 2D.4) plus the W2 structural-risk signal
(`no_arb_risk_flags` from 2B.4) into actionable, auditable decisions:
`abstain_flag` and `tradability_score`. Produces the project's first
**decision-grade output** — the system can now refuse to predict in unreliable
regions and grade the tradability of the regions it serves. The runner and
artifacts story (2D.6) consumes this layer end-to-end.

The decision rules are intentionally simple, explicit, and config-driven so the
operating point is auditable and tunable without code edits.

## Where this runs (local vs remote)

- **Local (Mac).** Entire story. Pure CPU NumPy / pandas: the decision layer
  is a tiny stateless transform over `PredictionResult` + risk-flag arrays.
  All implementation, configs, and unit tests are local-only.
- **Remote (RunPod): not required.** No GPU, no AV data dependency, no Pod
  time.

## Non-goals

- Do NOT change `eval/abstention.py` — that module produces
  abstention *curves* over all thresholds for evaluation; this story applies
  *one* threshold per operating point to emit a hard `abstain_flag`.
- Do NOT compute new uncertainty signals — pure consumption of 2D.4 + 2B.4.
- Do NOT train or retrain any model.
- Do NOT introduce learned thresholds — thresholds are config values; tuning
  them is an analyst decision driven by the abstention curves from 2A.4.
- Do NOT modify the `PredictionResult` schema. Decision outputs are produced
  alongside it (e.g. a `DecisionResult` dataclass), not jammed into it.

## Implementation steps

1. Define `DecisionResult` (immutable) in `eval/decision_layer.py` with:
   - `abstain_flag: np.ndarray[bool]`
   - `tradability_score: np.ndarray[float in 0..1]`
   - `decision_reason: np.ndarray[str]` (one of `ok`, `low_confidence`,
     `wide_interval`, `no_arb_violation`)
2. Define `DecisionConfig` loaded from `configs/decision_layer.yaml`:
   - `confidence_threshold: float` (e.g. 0.5)
   - `max_relative_width: float` (e.g. 0.5 — width / sigma_hat)
   - `forbid_flags: list[str]` (e.g. `["calendar_violation",
     "convexity_violation"]`)
   - `tradability_weights: {confidence: 0.6, width: 0.3, structure: 0.1}`
3. Implement `apply_decision_layer(prediction_result, no_arb_risk_flags,
   config) -> DecisionResult`:
   - `abstain_flag = (confidence < threshold) | (relative_width >
     max_relative_width) | any_forbidden_flag_set`
   - `tradability_score` = weighted combination of normalized confidence,
     inverse normalized width, and structural-flag indicator, clipped to
     `[0, 1]`. Document the formula in the module docstring.
   - `decision_reason` records the first triggering rule per row.
4. Unit tests:
   - Threshold behavior: a synthetic row with `confidence` just below /
     above the threshold flips `abstain_flag`.
   - Monotonicity: holding other inputs fixed, `tradability_score` is
     non-decreasing in `confidence` and non-increasing in `relative_width`.
   - Propagation: any forbidden flag forces `abstain_flag = True` regardless
     of confidence.
   - `decision_reason` prioritization is stable and matches the documented
     order.
5. Update `docs/logs/progress_log.md`.
