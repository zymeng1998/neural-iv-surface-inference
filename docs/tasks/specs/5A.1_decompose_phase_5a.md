## Purpose

Phase-entry decomposition for epic **5A — Reliability-First Surface
Inference / Quote-Risk Layer**. Per
[ADR 0011](../../decisions/0011_forward_strategy_accuracy_reliability_pricing.md),
Phase 5 formalizes the durable Phase 2–4 asset — the calibrated reliability /
abstention / no-arb / decision layer — into a coherent, desk-consumable
quote-risk system, and becomes the project's **primary contribution** if the
Phase 4B accuracy gate is negative (worth building regardless). This story
breaks Phase 5 into atomic child stories (5A.2+). Pure docs/planning — no
code, no run, no GPU.

## Where this runs

**Local (Mac), CPU-only.** Docs only.

## Implementation steps

1. Enumerate the target capabilities (calibrated uncertainty, abstention,
   surface-level confidence, no-arb/risk flags, quote/no-quote logic, spread /
   model-risk-reserve suggestions) against what Phase 2D / 4A already produce.
2. Map each capability to an atomic child story; identify gaps vs existing
   primitives.
3. Author the 5A.2+ child specs from `_template.md`; add `backlog` BOARD rows.
4. If the formalization makes a constraining architectural choice, author a
   Phase-5 design ADR.
5. Append progress_log; refresh STATUS; verify gates.
