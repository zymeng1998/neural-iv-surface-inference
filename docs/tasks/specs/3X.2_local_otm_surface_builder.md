## Purpose

Ship the OTM-restricted surface builder that turns the (dirty,
multi-valued) strict surface table into a **single-valued** IV surface
per [ADR 0006](../../decisions/0006_duplicate_coordinate_data_correction.md),
plus the step-04 plumbing to build benchmarks from it. Pure local code
+ tests on synthetic fixtures; **no real data on disk locally**, so no
real OTM file is produced in this story (that is 3X.4, on the Pod).

## OTM selection rule (ADR 0006 + D5 + D7)

Per `(date, expiration, strike)` row, with `spot = close`,
`log_moneyness = ln(strike/spot)`:

| Condition | Keep |
|---|---|
| `log_moneyness < -atm_band` (`K < S`, OTM put side) | the `put` leg |
| `log_moneyness >  atm_band` (`K > S`, OTM call side) | the `call` leg |
| `abs(log_moneyness) <= atm_band` (near-ATM) | the side with **tighter relative spread** `(ask - bid)/max(mid, eps)`; if tie or missing quote fields → deterministic fallback (declared order: `put`) |

- `atm_band` is **configurable**, default `0.0025` (D5).
- **No synthetic-quote construction** (no IV averaging / midpoint). The
  output is always one *observed* leg.

### Same-type residual duplicates (D7)

After the OTM rule, if any `(date, log_moneyness, tau)` key still has
> 1 row (same-type duplicate, e.g. two identical-type quotes):

1. Emit `artifacts/audits/otm_residual_same_type.csv` listing them.
2. Classify economic equivalence across `{bid, ask, mid,
   implied_volatility, volume, open_interest}` (within float tol).
3. If equivalent → drop after a stable sort (deterministic).
4. If not equivalent → keep the better-quality row (tighter relative
   spread; tie-break on higher `open_interest`, then `volume`).
5. `keep='first'` after stable sort is the **final documented
   fallback**; record how many rows hit it in the manifest.

## ATM-band evidence requirement (D5)

The builder manifest must report near-ATM counts at **all four** bands
`{1e-12, 0.001, 0.0025, 0.005}` so the operator can sanity-check the
default. The builder's `--dry-run` (on the synthetic fixture) prints
these. If, when 3X.4 runs on real data, the `0.0025` band selects an
implausible fraction of rows (e.g. > 5 % of contracts land in the ATM
tie-break), **stop and write an evidence note** proposing an alternative
band for operator approval — do not silently change the default.
