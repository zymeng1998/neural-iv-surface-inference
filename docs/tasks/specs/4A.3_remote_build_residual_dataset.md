## Purpose

Materialise the full residual-target dataset on
`spy_phase1_random40_noiselow_otm`: run the per-date RBF baseline at every
query coordinate (train/val/test) via the 4A.2 builder and store
`r = iv_true − rbf_pred` so 4A.4 can train `f_θ` on residuals without
recomputing RBF each epoch. CPU-heavy (RBF over the full OTM fold), so it is
its own remote story, mirroring 3X.6's RBF-on-OTM run.

## Where this runs

**Remote (RunPod) CPU pod** (no GPU). The 3X.6 RBF-on-OTM run is the cost
analogue (~minutes per split on CPU).

## Scope contract (atomic story)

- **One question:** what are the residual targets `r = iv − rbf_pred` across
  the full OTM train/val/test, and are they finite and consistent with the
  3X.6 RBF MAE (`rbf_pred` mean abs ≈ the RBF residual)?
- **One artifact bundle:** the committed residual-target manifest + summary
  under `artifacts/runs/4A3/` (residual parquet itself gitignored, pulled to
  local for 4A.4); per-split row counts + finiteness + residual stats.
- **One acceptance check:** residual row count == query row count per split;
  0 non-finite; `mean(|r|)` on each split matches the 3X.6 RBF MAE within
  tolerance (sanity that `rbf_pred` is the same baseline).
