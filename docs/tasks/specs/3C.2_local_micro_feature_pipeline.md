## Purpose

Land the **`feature_set` flag** on the conditional loader, encoder,
model, predictor adapter, and training loop so that
[ADR 0008](../../decisions/0008_microstructure_feature_set_freeze.md)'s
`micro_v1` per-quote feature tuple can be passed into 3C.3 training
without any downstream code change. **No training in this story.** Ship
the plumbing + tests; the remote retrain is 3C.3.

The flag is a hard contract: `feature_set ∈ {"minimal", "micro_v1"}`,
default `"minimal"`, so every committed 2D.* / 3A.* / 3B.* / 3X.*
checkpoint stays reproducible byte-for-byte and the existing test
suite stays green.

## Where this runs

**Local (Mac), CPU-only.** No Pod time.

## Scope contract (atomic story)

- **One question:** does the conditional pipeline correctly produce the
  9-dim `micro_v1` per-quote tuple, ingest it through `SetEncoder` and
  the predictor adapter, and round-trip via the checkpoint config —
  without disturbing the `minimal` default?
- **One artifact bundle:** the code patch (loader + encoder + model +
  predictor + training-loop passthrough) + three test files +
  `configs/conditional_3C2_micro_smoke.yaml` (a tiny smoke config used
  only by the integration test).
- **One acceptance check:** all new tests pass; the full regression
  suite (`pytest tests/`) stays green; legacy `minimal`-path forward
  pass is bit-for-bit equal to pre-change behaviour on a fixed seed.

- `tests/test_conditional_loader_micro.py` — unit tests on the loader:
  shape, ordering matches ADR 0008, `put_call_indicator ∈ {-1, +1}`,

  the pre-change loader for a frozen seed.
- `tests/test_set_encoder_micro.py` — unit tests on `SetEncoder` with
  `in_features=9`: shape round-trip, `return_elements=True` still
  works, padding-mask still masks padded rows.
- `tests/integration/test_micro_wiring.py` — integration test:
  `train_conditional` runs the smoke config end-to-end for 1 step
  with `feature_set="micro_v1"`; the saved checkpoint, when loaded via
  `ConditionalSurfacePredictor.from_checkpoint`, reconstructs the
  9-dim feature path; a forward pass on a fixed input produces a
  finite scalar loss.

## Non-goals

- Do NOT train any real model (3C.3 does that).
- Do NOT alter `_QUERY_FEATURES` — queries stay 2-dim `(log_moneyness,
  tau)`.
- Do NOT alter the data pipeline (`01_*` … `05_*`). All six new
  features already exist on `spy_surface_points_strict_otm.parquet`.
- Do NOT add a `mid` feature, `vix`, `realized_vol`, or any field
  listed under "Features explicitly out of scope" in ADR 0008.
- Do NOT change the `minimal` default — every legacy checkpoint must
  load and forward bit-for-bit identically.
- Do NOT introduce normalization stats in the loader (training-loop /
  manifest already owns z-score stats; 3C.3 fits new stats on the OTM
  train split).
- Do NOT touch ANP / DeepSets decoder internals — `decoder_kind` is
  orthogonal.
