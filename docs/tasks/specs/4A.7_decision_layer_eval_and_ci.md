## Purpose

Adjudicate the Phase 4 bar. Run the existing decision-layer runner on the
calibrated **hybrid** predictor (4A.4 + 4A.5 + 4A.6 calibrator), thresholds
held constant with 3X.12 (Q2 invariant), and compute the headline hybrid
test MAE / hi-conf / coverage / band-width / abstention / flag-violations on
OTM. Then run the **paired bootstrap CI** (new helper) on the per-query MAE
difference `(hybrid − RBF)` to decide whether the gain is statistically
meaningful (roadmap §2 / ADR 0010 §5).

## Where this runs

**Decision-layer eval** mirrors 3X.12 (CPU is sufficient if predictions are
cached; otherwise the GPU pod). The **bootstrap CI** is local CPU on the
committed per-query predictions.

## Scope contract (atomic story)

- **One question:** is the calibrated hybrid's OTM test MAE *statistically
  significantly* below the RBF floor (0.00613) — paired bootstrap 95 % CI on
  `(hybrid − RBF)` per-query MAE excluding 0 — while preserving reliability
  (coverage ±2 pp of 0.90; hi-conf < no-abstention; flags not meaningfully
  worse than 3X.12)?
- **One artifact bundle:** `results/4/spy_phase1_random40_noiselow_otm/4a_hybrid/`
  (metrics_summary + the bootstrap-CI result) + the eval manifest.
- **One acceptance check:** metrics computed with 3X.12 thresholds; the CI
  on the MAE delta is reported with its sign and bounds; the bar verdict
  (met / not met) is recorded — pass/fail is a *finding*, not a gate.
