## Purpose

Phase-entry decomposition for epic **4A — RBF-Prior Residual Hybrid**
(Phase 4). Authors the Phase 4 roadmap + [ADR 0010](../../decisions/0010_rbf_prior_residual_hybrid.md)
and breaks the work into atomic child stories 4A.2–4A.8. Pure
docs/planning — no code, no model, no GPU.

The hybrid predicts `σ̂ = RBF_t(k,τ) + f_θ(k,τ | context_t)`: RBF carries
the local interpolation it already wins (Phase 3 verdict), the neural model
learns the residual + the calibrated reliability layer. Success bar
(operator-set): any statistically meaningful accuracy gain over RBF-alone
(0.00613) **plus** preserved reliability — see roadmap §2 / ADR 0010 §5.
