## Purpose

Phase-entry decomposition story for epic **3X — Data correction** under
workstream **W11.5**. The 2026-05-29 duplicate-coordinate audit
([`docs/research/duplicate_coordinate_audit.md`](../../research/duplicate_coordinate_audit.md))
found that **93.61 %** of strict-surface rows are call-put leg
duplicates at the same `(date, log_moneyness, tau)` model coordinate,
with median in-group IV range 0.049, and **37.46 %** of held-out rows
in `spy_phase1_random40_noiselow` carry an exact-coordinate observed
twin — invalidating the single-valued-function assumption the
conditional model and the RBF baseline both rely on
([ADR 0006](../../decisions/0006_duplicate_coordinate_data_correction.md)).

3X.1 decomposes the correction into atomic stories under the
**preservation-first** principle: nothing existing is mutated; all new
artifacts carry an `_otm` suffix; the deliverable is a side-by-side
dirty-vs-OTM comparison on the matched `random40_noiselow` substrate.

## Decisions locked into this decomposition (operator-confirmed)

These refine [ADR 0006](../../decisions/0006_duplicate_coordinate_data_correction.md);
see its addendum for the full record.

- **D1** — retrain **all three** ANP heads on OTM (gaussian, quantile,
  point_control). No head dropped.
- **D2** — retrain the Phase 2D DeepSets family on OTM (2D.7-equiv
  single + 2D.8-equiv K=5 ensemble).
- **D3** — rebuild **all 11** OTM benchmark variants; audit all of them.
- **D4** — paired-coordinate masking ships behind a flag, **default
  off**; the OTM audit gate is the trigger that makes it mandatory
  (any benchmark with > 0.5 % exact-twin leakage per split blocks use).
- **D5** — configurable ATM band (default `0.0025`) for the OTM
  tie-breaker, with sensitivity reporting at `{1e-12, 0.001, 0.0025,
  0.005}`; tie-break on tighter relative spread; deterministic
  documented fallback; **no synthetic-quote construction**.
- **D6** — keep audit v1 as historical evidence; add vectorised audit
  v2 with parity tests.
- **D7** — same-type residual duplicates: classify, drop deterministically
  only if economically equivalent, else quality-select; `keep='first'`
  is the documented final fallback with a reported count.
- **D8** — retrain from scratch, same seeds as the dirty runs, no
  warm-start from dirty checkpoints.
- **Q1** — include MLP-on-OTM in the baseline ladder.
- **Q2** — hold the decision-layer threshold config constant between
  dirty and OTM (no retune inside 3X).
- **Q3** — 3X.14 produces only the 3X closing addendum + methodology
  progression; the full Phase 3 memo remains a 3D deliverable.
- **Q4** — split Pod rental: CPU pod for the build + audit gate
  (3X.4–3X.6), human review, then GPU pod for retraining (3X.7–3X.12).
- **Q5** — if 2D-on-OTM beats RBF-on-OTM (or ANP), do **not** reopen
  Phase 2; record a retrospective / ADR addendum and update the
  forward roadmap.
- **Q6** — the 3C sparse-region study reopens only after 3X.14, on the
  OTM substrate, if the audit gate passed.
- **Q8** — audit v2 ships (3X.3) before the OTM audit gate (3X.5).

### Primary retraining substrate (operator-confirmed)

The primary dirty-vs-OTM model-family retraining (3X.6–3X.12) runs on
**`spy_phase1_random40_noiselow_otm` only** — the clean apples-to-apples
counterpart to the original dirty `random40_noiselow` experiments. This
isolates the substrate correction without simultaneously changing the
masking / noise regime. All 11 OTM variants are still **rebuilt and
audited** (3X.4 / 3X.5) for substrate completeness and to support the
deferred robustness study. **Full all-11 OTM retraining is explicitly
future work** (see the roadmap §W11.5 future-work block and the
no-overclaim guardrail below).

### No-overclaim guardrail (must propagate to 3X.13 / 3X.14 and 3D)

- Correct claim: *"The original Phase 2D / Phase 3B result was restated
  on the matched clean OTM benchmark `random40_noiselow_otm`."*
- Forbidden claim: *"The result is robust across all OTM benchmark
  variants."* — that requires the deferred all-11 retraining study.
