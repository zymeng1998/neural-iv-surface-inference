## Purpose

Train a K=5 deep ensemble of the **residual point head** (4A.4 backbone) on
OTM, mirroring 3X.10 (which mirrored 3B.5 / 2D.8). The ensemble disagreement
feeds the calibrated production predictor (4A.6) as the uncertainty signal on
the summed hybrid `σ̂ = rbf_pred + f_θ`.

## Where this runs

**Remote (RunPod) GPU pod**, same tier/window as 4A.4. Seeds
`[101, 202, 303, 404, 505]`.

## Scope contract (atomic story)

- **One question:** what is the K=5 residual-ensemble summed-hybrid test MAE
  and the mean ensemble disagreement on OTM, vs the 4A.4 single point head
  and vs RBF (0.00613)?
- **One artifact bundle:** `artifacts/runs/4A5/ensemble/` (manifest +
  training curves + per-row val/test predictions of the summed hybrid +
  per-member disagreement).
- **One acceptance check:** all 5 members finite; ensemble disagreement > 0;
  summed-hybrid MAE + Δ-vs-4A.4-single + Δ-vs-RBF journaled.

## Dependencies

- 4A.4 `done` (the residual point config/backbone is the per-member recipe).

## Implementation steps

1. Clone the 3X.10 ensemble config; set `target_mode: residual`; keep seeds.
2. Run the 5 members (same Pod window as 4A.4), `tee` logs.
3. Reconstruct summed hybrid per member; aggregate mean + disagreement.
4. Pull manifest + curves + predictions to local.
5. Journal: ensemble summed-hybrid MAE, disagreement, deltas.
6. PMR gate dry-run; flip BOARD → `in_review`.
