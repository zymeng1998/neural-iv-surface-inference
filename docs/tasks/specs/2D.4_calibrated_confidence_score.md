## Purpose

Fuse the three W4 uncertainty sources — the heteroscedastic / quantile interval
from 2D.2, the deep-ensemble disagreement from 2D.3, and the
masking-sensitivity signal already produced by 2B.2 — into a single per-point
`confidence_score` and a calibrated `(lower, upper)` band. Fill the previously
empty `PredictionResult.uncertainty / .lower / .upper` slots on the conditional
predictor and verify that empirical interval coverage tracks the nominal level
on a held-out fold using the existing W1 metrics from 2A.

This is the story that produces the project's first **calibrated** reliability
signal. Decisions (abstention, tradability) are 2D.5.

## Where this runs (local vs remote)

- **Local (Mac).** The fusion + calibration code (`eval/calibration.py`),
  `CalibratedConditionalPredictor`, `scripts/run_calibration_fit.py`,
  `configs/calibration.yaml`, and all unit tests. Calibration itself is fit
  on **cached val predictions pulled from the Pod** (the per-row CSVs
  produced by the 2D.2-R and 2D.3-R runs), so the fit is CPU-only and
  reproduces locally. The masking-sensitivity signal from 2B.2 likewise
  reuses cached predictions.
- **Remote (RunPod): not required for this story.** No new training; if a
  fresh inference pass over the AV test fold is needed to verify
  out-of-sample coverage, schedule it as part of 2D.6's end-to-end run
  rather than re-spinning the Pod here.

## Non-goals

- Do NOT introduce new uncertainty *sources* — only fuse and calibrate the
  three that exist (2D.2 interval, 2D.3 ensemble disagreement, 2B.2 masking
  sensitivity).
- Do NOT make abstention or tradability decisions — 2D.5.
- Do NOT modify 2A W1 metrics or 2B W2 diagnostics; this story only *consumes*
  them.
- Do NOT retrain any model — the calibrator is fit on cached predictions over
  a held-out fold of the existing benchmark.
- Do NOT introduce a new dataset split scheme. Use the existing val/test split
  from the AV benchmark.

## Implementation steps

1. Decide and document the fusion formula in `eval/calibration.py`:
   - Combined raw uncertainty `u = f(sigma_hetero, std_ensemble, sigma_masking)`
     (default: per-source z-score then quadrature sum; alternatives noted but
     not implemented).
   - `confidence_score = sigmoid(-(u - u0) / s)` where `(u0, s)` are fit on
     val.
2. Implement calibration on the **validation** fold:
   - Gaussian head: temperature scaling `sigma_cal = T * sigma_hetero` chosen
     so empirical coverage matches nominal `alpha`.
   - Quantile head: split-conformal adjustment of `(q_lo, q_hi)` on val
     residuals.
   - Ensemble disagreement: a monotone mapping `disagreement → sigma_eq` fit
     on val so it can be combined in the same units as the interval.
3. Implement `CalibratedConditionalPredictor` in `eval/adapters.py` that wraps
   any underlying `Predictor` (2D.2 head, 2D.3 ensemble, or both) plus a fit
   `Calibrator` and emits a `PredictionResult` with all four signals filled:
   `sigma_hat`, `uncertainty`, `lower`, `upper`.
4. Write `scripts/run_calibration_fit.py`: load val predictions, fit the
   calibrator, persist to `artifacts/calibration/{run_id}.json`.
5. Verify with the **existing W1 metrics** (`eval/uncertainty_metrics.py`):
   - `prediction_interval_coverage` on test must equal nominal within a
     documented tolerance (default ±2 percentage points at nominal 90%).
   - `error_vs_uncertainty_correlation` on test must be positive and
     statistically non-zero.
6. Unit tests:
   - On a synthetic Gaussian fixture with known noise, temperature scaling
     recovers the true scale within tolerance.
   - On a synthetic asymmetric fixture, conformal adjustment produces
     coverage at nominal within tolerance.
   - Fusion is monotone increasing in each source.
7. Append an `experiment_journal.md` entry with the calibrated test-set
   coverage, mean width, and high-confidence MAE compared to the uncalibrated
   conditional baseline.
