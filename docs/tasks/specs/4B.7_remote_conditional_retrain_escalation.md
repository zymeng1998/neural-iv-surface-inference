## Purpose

**Conditional escalation** for the staged design. The 4B.4/4B.5 eval-time sweep
stresses a checkpoint trained on *full* context against *sparse* context, which
carries a fairness caveat. **Only if 4B.5 returns `ambiguous`** (trend present
but CIs do not separate, or the caveat materially clouds the read), this story
**retrains** the RBF-prior hybrid *per rung* on the contested regime(s) for an
apples-to-apples comparison, then recomputes that regime's trajectory and
finalizes the gate. **If 4B.5 is unambiguous (`true`/`false`), this story is set
`cancelled`** with a one-line rationale — no Pod spend.

## Where this runs

**Remote (RunPod), GPU.** Per-rung retraining = multiple GPU windows — the
heaviest 4B compute. Rent only when triggered.

## Dependencies

- 4B.5 `done` **and** its `gate_verdict.json` = `ambiguous` (the trigger). If
  the verdict is `true`/`false`, cancel this story instead of running it.
- 4A.3 `done` (residual-target build path, reused per rung) + 4A.4 `done`
  (the training recipe to mirror).

## Scope contract (atomic story)

- **One question:** under a *fair* per-rung retrain, does the contested
  regime's edge grow materially or not (resolving the ambiguity)?
- **One artifact bundle:** per-rung retrained checkpoints (Pod) + refreshed
  `4b_sweep/` trajectory rows for the contested regime + a resolved
  `gate_verdict.json`.
- **One acceptance check:** the contested regime's trajectory is recomputed
  from fairly-trained models and `accuracy_survives` flips to `true`/`false`.

1. Gate on `4b_sweep/gate_verdict.json == ambiguous`; otherwise cancel.
2. Per contested rung: build the rung's residual targets (reuse 4A.3 path),
   retrain the hybrid (mirror 4A.4), forward + sum → σ̂.
3. Recompute that regime's trajectory + CIs (reuse 4B.5); update
   `gate_verdict.json` to a resolved `true`/`false`.
4. Append journal; update progress_log / STATUS; hand to 4B.6 for the close.
