## Purpose

Run the 2D.6 decision-layer evaluation on the OTM substrate using the
OTM ANP (3X.9) + OTM ensemble (3X.10) + OTM calibrator (3X.11), with the
**decision-layer threshold config held constant** vs the dirty 2D.9 /
3B.7 run (Q2). This isolates the data-substrate correction; it does not
retune the decision policy. Mirrors 3B.7 on the clean benchmark.

benchmark parquet, both Pod-side (as in 3B.7). GPU optional; the runner
is light, but it runs where the data lives. Bundle pulled back +
committed under `results/3/..._otm/`.
