## Purpose

Remote counterpart to the local code landed in 3B.2 / 3B.3. Train the
ANP cross-attention conditional model end-to-end on the Alpha Vantage
benchmark across the three head kinds, matching the 2D.7 sweep line
for line:

- `head.kind: gaussian` (heteroscedastic Gaussian NLL),
- `head.kind: quantile` (pinball loss, default `(0.05, 0.5, 0.95)`),
- `head.kind: point` (regression control — parity check against 2C / 3A
  raw baseline on the same benchmark).

Produces the per-row val/test predictions, per-epoch training logs,
and final-metric summaries that downstream stories consume: 3B.5 deep
ensemble (parallels 2D.8 on ANP), 3B.6 calibrator re-fit (parallels
2D.4), and 3B.7 end-to-end decision-layer scoring (parallels 2D.9).

## Where this runs

**Remote (RunPod) only.** Three full conditional trainings on the AV
benchmark with the new ANP decoder. Checkpoints live Pod-side under
`runs/3B4/<head_kind>/checkpoints/`; the manifest + training curves +
per-row val/test predictions are pulled back to the laptop and
committed.

## Scope contract (atomic story)

- **One question:** what are the val / test Gaussian NLL, test MAE,
  and quantile coverage / monotonicity of three end-to-end ANP
  trainings on the AV benchmark, matched to 2D.7's protocol (same
  dataset, same seed, same optimizer / schedule, same head dispatch)?
- **One artifact bundle:**
  `artifacts/runs/3B4/{gaussian,quantile,point_control}/` — each with
  `manifest.json`, `training_curve.csv`, `val_predictions.csv`,
  `test_predictions.csv`. Schema matches 2D.7's bundle exactly.
- **One acceptance check:** all three runs complete with non-NaN
  losses; quantile-monotonicity holds on test; point-control parity
  vs the 3A.3 raw baseline is documented (no hard pass-fail —
  end-to-end retrain *should* differ from frozen-encoder retrain,
  but the delta is journaled).

## Compute requirements

This story has three compute phases. Plan Pod rental around (3); (1)
and (2) are local / free.

| Phase | Locale | Hardware | VRAM | Wall time | Disk |
|---|---|---|---|---|---|
| (1) Configs + runner code | local Mac | CPU-only | n/a | ~30 min dev | <50 KB |
| (2) Pod smoke (gaussian variant, `epochs: 2`) | remote (RunPod) | single GPU — same tier as 2D.7 (typical: RTX 4090 / A40 / A100-40GB; current Pod: RTX PRO 4000 Blackwell per 3A.3) | ~8–12 GB (ANP cross-attention adds modest per-step memory vs 2D.7) | ~5–10 min wall | <50 MB |
| (3) Three full runs (50 epochs each, matched to 2D.7) | remote (RunPod) | single GPU — same tier as 2D.7 | ~8–12 GB | end-to-end retrain ≈ 1.5–2× per-head wall vs 2D.7 (encoder + decoder both train); expected ~45–60 min wall **per head**, run sequentially → **~2.5–3 h total Pod wall**, plus ~10 min overhead for the sequential sweep | manifest + curves + predictions ≈ ~30 MB committed per head (90 MB total); checkpoints ~300 MB per head (gitignored) |

- **Disk — Pod working set:** ~3 × (300 MB ckpt + 50 MB scratch
  predictions) ≈ ~1.1 GB. Reuse the same Pod / volume the 2D.7 +
  3A.3 runs used (the AV benchmark is already on disk;
  exclude it from this number). **Recommend ≥ 8 GB free on the Pod
  volume** to absorb checkpoint sweeps without trimming.
- **Recommended Pod rental window:** ~4 h to cover phase (2) smoke
  + phase (3) sequential runs + buffer for rsync / log retrieval.
  Use the same Pod tier you used for 2D.7 / 3A.3. **Push code +
  configs first**, then start the Pod — the operator should not pay
  for idle Pod time while local edits land.
- **Sequential vs parallel:** the three heads are independent — if
  the operator wants ~half the wall time and is willing to pay for
  three GPUs, the three configs can run on three Pods concurrently.
  Default is sequential on a single Pod (cheaper, simpler).
- **Notes:** no multi-GPU and no high-VRAM tier required. ANP
  cross-attention adds ~2× per-step compute vs DeepSets but the
  model is still small relative to typical NLP transformers; the
  Pod tier that fit 2D.7 / 3A.3 fits this comfortably. If the Pod
  picks up the 2D.7 torch / CUDA stack already in 3A.3 (torch
  2.11.0+cu128 on the Blackwell Pod), no extra venv work is needed.

   `head.kind`. Do not change seed, optimizer, schedule, or epochs.
4. Author `scripts/run_3b4_single.py` (thin runner) and
   `scripts/run_conditional_3B4.sh` (sequential Pod launcher).
   Redirect each variant's output to its own log file.
5. **Pod smoke:** one config (`gaussian`), `epochs: 2` override,
   end-to-end. Confirm the manifest shows `decoder_kind: anp`,
   `coord_encoding.kind: raw`, `freeze_encoder: false`, and seed 42.
6. **Pod full runs:** gaussian → quantile → point_control,
   sequentially, each with its own log redirect. Expected wall
   ≈ 45–60 min per head on the standard 2D.7 hardware.
7. Pull all three artifact bundles back via rsync (manifest +
   training curves + val/test predictions; **not** checkpoints).
   Commit the bundles per the existing `artifacts/runs/**/*.parquet`
   convention added in 3A.3.
8. Append a short `experiment_journal.md` entry pointing at the
   three committed bundles with headline metrics (val NLL, test NLL,
   test MAE per head; quantile-monotonicity flag; point-control
   delta vs the 3A.3 raw baseline). Numbers are reported here;

10. Update `docs/PHASE3_INDEX.md` per-story Last checkpoint and the
