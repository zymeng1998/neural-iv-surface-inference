## Purpose

Phase-entry decomposition story for epic **3A — Coordinate-Representation
Ablation** under workstream **W10**. Mandatory first story of every epic
per [`docs/workflows/ai_human_collaboration.md`](../../workflows/ai_human_collaboration.md)
§4 ("phase-entry decomposition").

3A is a **single controlled experiment** that diagnoses whether the
gap-to-RBF on the current architecture is:

- an **input-representation problem** (coordinate-MLP spectral bias on
  raw `(k, τ)`; Rahaman et al. *ICML* 2019; Tancik et al. *NeurIPS*
  2020), or
- an **architecture problem** (mean-pool decoder cannot exploit
  query-local context).

Experiment: Fourier-encoded `(k, τ)` vs raw `(k, τ)` on the existing
`SetEncoder + MultiOutputDecoder` (Gaussian head), **decoder-only
retrain on the frozen 2D.7 encoder**, all else equal versus the
production baseline. Single decoder-only training run on the Pod
(~30 min), one bundle of metrics, no architectural change.

3A is intentionally small. It does **not** ship a new production
predictor. It exists for clean attribution: its result is a parameter
input to 3B's coordinate-encoding default, not a gate on 3B.

## Explicit non-scope (Phase 3 framing decisions)

These were considered and **rejected** for 3A, per
[ADR 0004](../../decisions/0004_phase3_accuracy_push_framing.md):

- **Neural-residual-on-RBF hybrid (`iv_hat = RBF + Δ`)** — concedes the
  central research question ("can the neural model re-derive
  RBF-equivalent local-weighting from data?") by using RBF as
  scaffolding. Reserved as a **Phase 4 production fallback** if Phase
  3 closes without meeting the acceptance bar.
- **SIREN** — inductive bias targets periodic implicit representations
  (SDFs, audio); IV surfaces are non-periodic in `(k, τ)`. Wrong tool.
- **Encoder retraining** — 3A is decoder-only on a frozen encoder, so
  the only thing that varies is coordinate encoding. Any encoder
  retraining belongs in 3B.
