## Purpose

Train the residual model `f_θ` across heads {gaussian, quantile, point} on
`spy_phase1_random40_noiselow_otm`, fitting the residual target from 4A.3.
The **default backbone is ANP-residual** — the 3X.9 DeepSets+ANP recipe with
`target_mode: residual` (ADR 0010 §Decision 3a). The headline hybrid
prediction is `σ̂ = rbf_pred + f_θ`; this story reports both the residual-fit
quality and the **summed** hybrid MAE vs the RBF floor (0.00613) and the
3X.9 pure-neural reference.

## Where this runs

**Remote (RunPod) GPU pod** (3X.9 tier: RTX A4500 / 4090 / A40). Sequential
3-head run mirroring 3X.9.

## Scope contract (atomic story)

- **One question:** what is the residual-hybrid summed test MAE per head on
  OTM, and how does it compare to the RBF floor (0.00613) and to pure-neural
  3X.9 (gaussian 0.01440 / quantile 0.01175 / point 0.00987)?
- **One artifact bundle:** `artifacts/runs/4A4/{gaussian,quantile,point}/`
  (manifest + curve + per-row val/test predictions of **both** `f_θ` and the
  summed `σ̂`).
- **One acceptance check:** all three finite; quantile monotone on test;
  manifests carry `target_mode=residual`, backbone, dataset/config/seed/code
  hashes; summed-hybrid MAE + delta-vs-RBF + delta-vs-3X.9 journaled per head.

## Implementation steps

1. Confirm 4A.3 residuals on the pod; clone 3X.9 configs, set
   `target_mode: residual`.
2. Run gaussian → quantile → point sequentially (`tee` per head).
3. Reconstruct `σ̂ = rbf_pred + f_θ`; score hybrid MAE on val/test.
4. Pull manifests + curves + per-row predictions to local.
5. Journal per-head: residual-fit MAE, summed-hybrid MAE, Δ-vs-RBF,
   Δ-vs-3X.9; note the backbone decision.
6. PMR gate dry-run; flip BOARD → `in_review`.
