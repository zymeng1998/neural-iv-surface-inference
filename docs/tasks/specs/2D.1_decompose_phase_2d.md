## Purpose

Phase-entry decomposition story for epic 2D (Phase 2 Workstreams W4 — *Uncertainty-
Aware Neural Inference* + W5 — *Abstention and Tradability Decision Layer*). It
pulls epic 2D into active work, breaks it into atomic stories each sized for one
focused session, writes a spec per story, and registers them on the board at
`backlog`. Mandatory first story of every epic per the operating model §4
("phase-entry decomposition").

Epics 2A (W1 measurement), 2B (W2 diagnostics), and 2C (W3 conditional model)
are all `done`. The Phase 1 baselines and the conditional Set-Encoder+Decoder
have been re-run against the Alpha Vantage dataset (2C.8). What is still
missing is the *reliability output* that motivates the project: the conditional
model currently emits point predictions only — `PredictionResult.uncertainty`,
`.lower`, `.upper` are all `None`.

Epic 2D fills these slots and converts the resulting reliability signals into
**decision-grade outputs**: `confidence_score`, `uncertainty_band`,
`tradability_score`, `no_arb_risk_flags`, and `abstain_flag`. By the end of 2D,
the system can refuse to predict in unreliable regions and emit a calibrated
confidence on the regions it does serve.

W4 supplies the uncertainty signals; W5 turns them into decisions. The two
workstreams share an evaluator (the W1 layer from 2A) and a structural-risk
input (the W2 `no_arb_risk_flags` from 2B), so they decompose as one epic.

## Story breakdown (the decomposition)

| Story | Scope | W4/W5 element | Depends on |
|---|---|---|---|
| 2D.2 Heteroscedastic / quantile predictive head | Add an uncertainty head to the W3 conditional decoder: either a Gaussian head emitting `(mu, log_sigma^2)` trained with Gaussian NLL, or a quantile head emitting `(q_lo, q_med, q_hi)` trained with pinball loss. Update `train_conditional.py` + `configs/conditional.yaml` to support the new objective behind a config switch (default off → backward compatible with 2C). Unit tests on shapes, monotone quantile ordering (if quantile), and finite-loss sanity. | W4 — predictive intervals | 2C |
| 2D.3 Deep ensemble disagreement | Train K (default 5) seeded copies of the conditional model from 2C; build an `EnsembleConditionalPredictor` `Predictor` adapter that aggregates member predictions into a mean `sigma_hat` plus a disagreement signal (std across members). Driver script `scripts/run_ensemble_train.py`. No new architecture — pure replication + aggregation. | W4 — ensemble disagreement / model-disagreement uncertainty | 2C |
| 2D.4 Calibrated confidence score | Combine the W4 uncertainty sources — heteroscedastic/quantile interval (2D.2), ensemble disagreement (2D.3), and the W2 masking-sensitivity signal — into a single per-point `confidence_score` plus `uncertainty_band` (`lower`, `upper`). Calibrate intervals on a held-out fold (temperature scaling for Gaussian, conformal adjustment for quantile) and verify empirical coverage tracks nominal within a documented tolerance using the W1 metrics. Fills `PredictionResult.uncertainty/lower/upper`. | W4 — calibrated `confidence_score` | 2D.2, 2D.3 |
| 2D.5 Abstention + tradability + risk-flag decision layer | New `eval/decision_layer.py` that consumes `(sigma_hat, confidence_score, lower, upper, no_arb_risk_flags_from_2B)` and emits `abstain_flag`, `tradability_score`, and a region-level decision table. Thresholds are config-driven (`configs/decision_layer.yaml`) so the operating point is auditable. Unit tests on threshold behavior, monotonicity of `tradability_score` in confidence, and on the `no_arb_risk_flags → abstain_flag` propagation rule. | W5 — abstention + tradability decision layer | 2D.4, 2B.4 |
| 2D.6 Decision-layer end-to-end runner + artifacts + journal | New `scripts/run_decision_layer_eval.py` that, for each benchmark dataset and each predictor (interpolation, MLP, point conditional, calibrated conditional from 2D.4), runs the full pipeline through the W1 uncertainty evaluator *and* the new decision layer and writes a region/regime summary table plus abstention-vs-error curves. Commit result artifacts under `results/2D/` and append a `docs/experiments/experiment_journal.md` entry comparing the abstention-enabled conditional predictor against the Phase 1 floors and the point-only Phase 2C model. | W5 — decision-grade artifacts and evidence | 2D.5, 2A.5, 2B.5, 2C.5 |

Sequencing rationale:

- **2D.2 and 2D.3 are independent** uncertainty sources and can be worked in
  parallel (or in either order). 2D.4 synthesizes them, so it depends on both.
- **2D.5 depends on 2D.4 (signal) and 2B.4 (risk flags)**; it is the first
  story that produces an `abstain_flag`.
- **2D.6 is last** — it is the evidence story and must run against finished
  upstream code.
