## Purpose

Wire the masking-sensitivity harness (2B.2), no-arbitrage diagnostics (2B.3), and
risk-flag synthesis + heatmaps (2B.4) into one end-to-end runner that evaluates a
predictor on a benchmark and emits committed diagnostic artifacts. This is the
integration story that makes W2 usable and follows the same evidence-discipline
pattern as the W1 runner (2A.5): result CSVs committed, figures regenerable, run
logged in the experiment journal.

## Implementation steps

1. `diagnostics/report.py`: assemble tidy tables — a per-date / per-region
   diagnostics summary (violation counts, rates, severities, mean instability,
   risk-flag rate) and a long-form region grid suitable for heatmaps.
2. `scripts/run_structure_diagnostics.py`: CLI mirroring the W1 runner
   (`--benchmark` | `--synthetic`, `--predictor interp`, `--out-dir`, `--tag`,
   sampling caps for runtime). Loads splits, runs the predictor, computes
   masking sensitivity + no-arb diagnostics + risk flags, writes
   `artifacts/results/structure_diagnostics_*.csv` and region heatmap figures,
   with importable helpers (`make_synthetic_benchmark` reuse, `run_diagnostics`,
   `write_artifacts`).
3. Append an experiment-journal entry (dataset, predictor, headline violation /
   instability numbers, artifact paths).
4. Test end-to-end on a tiny synthetic fixture: artifacts created, CSV has the
   expected columns, region grid well-formed, runs through the full
   predictor → diagnostics → artifacts path.
