## Purpose

Train the W3 conditional model (2C.3 modules over 2C.2 date-grouped batches)
end-to-end. This produces the first checkpoint of a surface model that ingests
the observed chain. The loop mirrors the existing baseline conventions in
`training/train.py` and `configs/baseline.yaml` — config-driven hyperparameters,
checkpoint on best validation loss, per-epoch train/val logging, early stopping,
and seed control — so the conditional model is trained and reported on the same
footing as the Phase 1 baselines.

## Non-goals

- Do NOT run the full RunPod training in this story (raw data is RunPod-only);
  the local deliverable is a *synthetic smoke* that proves the loop converges on
  a toy frame. The real run is a documented follow-up.
- Do NOT wire the `Predictor` interface or run the uncertainty/diagnostics
  evaluators (2C.5).
- Do NOT add W4 reliability heads (heteroscedastic/quantile/ensemble).
- Do NOT modify the baseline training loop or `configs/baseline.yaml`.
- Do NOT redirect verbose training output into the conversation — write to a log
  file and report only summary numbers (per CLAUDE.md context rules).

## Implementation steps

1. Write `tests/test_train_conditional.py` first (RED): build a tiny synthetic
   date-grouped dataset (reuse 2C.2), run 1–2 epochs, assert a checkpoint file is
   written and final train loss < initial train loss.
2. Implement `train_conditional.py`: `train_one_epoch` / `evaluate` over
   date-grouped batches; masked loss on query points (mask out padded queries);
   best-val checkpointing; early stopping; per-epoch logging; seeded.
3. Add `configs/conditional.yaml` mirroring `baseline.yaml` (model dims, latent
   dim, lr, batch size, epochs, patience, seed, dataset name).
4. Add `scripts/run_conditional.py` (config-driven entrypoint; writes checkpoint
   + training log under `artifacts/`). Redirect verbose output to a log file.
5. Run the smoke test (GREEN). Run the PMR gate; update progress log + roadmap +
   data lineage as applicable.

- [ ] Config-driven (no hardcoded hyperparameters); seeded run is reproducible.
- [ ] New + existing tests pass; PMR gate dry-run passes.
- [ ] Baseline training loop + `baseline.yaml` unchanged.
