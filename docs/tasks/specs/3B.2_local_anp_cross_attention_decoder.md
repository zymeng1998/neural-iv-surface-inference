## Purpose

Land the local code that turns the architectural pick in
[ADR 0005](../../decisions/0005_cross_attention_architecture_choice.md)
into a runnable model: an **Attentive Neural Process (ANP) cross-
attention decoder** module that composes with the existing DeepSets
`SetEncoder`, plus a `decoder_kind` flag on `ConditionalSurfaceModel`
to select between the Phase 2 `MultiOutputDecoder` (mean-pool baseline)
and the new ANP decoder, plus the unit / synthetic-smoke / integration
tests that prove the module is correct without spending Pod time.

No training run. No Pod time. The Pod runs are 3B.4 / 3B.5.

## Scope contract (atomic story)

- **One question:** does the ANP cross-attention decoder module compose
  correctly with the existing `SetEncoder` to produce a forward pass
  that is differentiable end-to-end, mask-respecting, and head-kind-
  agnostic?
- **One artifact bundle:** the decoder module + the `decoder_kind`
  flag + the test files listed in `file_scope`. No checkpoints, no
  predictions, no Pod artifacts.
- **One acceptance check:** all listed tests pass locally, including
  a 1-epoch synthetic-smoke train that confirms the new decoder both
  reduces loss and exercises the cross-attention path (per the test
  assertions below).

## Files likely to touch

### New

- `src/neural_iv_surface_inference/models/anp_decoder.py` —
  implementation of the ANP cross-attention decoder block. Public API:

  ```python
  class ANPDecoder(nn.Module):
      def __init__(
          self,
          *,
          d_h: int,            # per-element embedding dim from SetEncoder
          d_z: int,            # global summary dim (z_t)
          d_query: int,        # coord-encoded query dim (raw (k, τ) → 2)
          n_heads: int = 4,
          d_head: int | None = None,  # default d_h // n_heads
          mlp_hidden: int = 128,
          head_kind: Literal["gaussian", "quantile", "point"] = "gaussian",
          quantiles: tuple[float, ...] = (0.05, 0.5, 0.95),
          include_z_in_decoder: bool = True,
      ) -> None: ...

      def forward(
          self,
          *,
          H: Tensor,           # [B, N_ctx, d_h]  per-element keys/values
          mask: Tensor,        # [B, N_ctx] bool, True = real, False = pad
          z: Tensor,           # [B, d_z]    global summary
          q: Tensor,           # [B, N_q, d_query] coord-encoded queries
      ) -> Tensor:             # head-kind-dependent output, [B, N_q, K]
          ...
  ```

  Internals: multi-head **cross-attention** with `query = MLP_q(q)`,
  `key, value = MLP_kv(H)`; padded positions in `mask=False` get
  `-inf` softmax logits; output context vector `c_q ∈ R^{d_h}`;
  decoder MLP takes `[z, c_q, q]` (or `[c_q, q]` if
  `include_z_in_decoder=False`) → head dispatch identical to
  `MultiOutputDecoder` (`gaussian: (mu, log_sigma2)`,
  `quantile: (q_lo, q_med, q_hi)` with inference-time ordering,
  `point: (mu,)`).

- `tests/test_anp_decoder.py` — pure-unit tests on `ANPDecoder`:
  shape parity, mask correctness, gradient flow, head-kind dispatch,
  determinism under fixed seed. Synthetic tensors only; no dataset.

- `tests/integration/test_anp_wiring.py` —
  `pytest.mark.integration`. Exercises the full
  `ConditionalSurfaceModel` with `decoder_kind: anp` on a tiny
  synthetic dataset for 1 epoch, asserting:
  - Loss decreases over 50 steps (smoke).
  - `decoder_kind: deepsets` (the existing baseline path) still
    produces bit-for-bit identical outputs versus the current
    `MultiOutputDecoder` on a fixed input batch (regression guard).
  - Per-element-mask shuffling of the context set leaves the model
    output for a fixed query *invariant* (set-equivariance check).
  - Masking out all context elements except one produces a finite,
    non-NaN output (degenerate-mask robustness).

### Touched

- `src/neural_iv_surface_inference/models/conditional_surface.py` —
  add a `decoder_kind: Literal["deepsets", "anp"] = "deepsets"`
  argument on `ConditionalSurfaceModel.__init__`. When `"anp"`,
  instantiate `ANPDecoder` instead of `MultiOutputDecoder`; otherwise
  preserve existing behavior bit-for-bit. The `SetEncoder` must
  expose the pre-pool per-element tensor `H` alongside the pooled
  `z` (already required for ANP) — add a `return_elements=True`
  branch on `SetEncoder.forward` if not already present, keeping the
  default behavior unchanged.

- `configs/conditional.yaml` — add a `decoder_kind: deepsets` field
  to the `conditional` block, default `deepsets`. Document under it
  the `anp` sub-block with `n_heads`, `d_head`, `mlp_hidden`,
  `include_z_in_decoder`. Reuse the existing `head:` block — head
  kind selection is unchanged.

## Non-goals

- Do NOT run any training on AV data. Only synthetic smoke / unit
  tests in this story.
- Do NOT add a new head kind. Reuse the existing
  `gaussian / quantile / point` dispatch from 2D.2.
- Do NOT add Fourier coordinate encoding to the ANP decoder. Default
  is **raw `(k, τ)`** per 3A's measured result. (The
  `coord_encoding` flag from 3A.2 remains live; the operator may set
  it to `fourier` in a follow-up ablation, but that is not 3B.2's
  responsibility.)
- Do NOT change the Phase 2 `SetEncoder` architecture beyond
  optionally exposing pre-pool per-element tensors.
- Do NOT modify the existing `MultiOutputDecoder` code path. ANP is
  a parallel `decoder_kind`, not a replacement.
- Do NOT add a Set Transformer encoder, TNP, or Perceiver IO variant
  (ADR 0005 explicitly defers these).
- Do NOT touch any 3A / 3C / 3D file.
- Do NOT exceed `file_scope`. Predictor-adapter wiring is 3B.3;
  full-AV training is 3B.4.

   `src/neural_iv_surface_inference/models/anp_decoder.py` matching
   the public API above. Use `torch.nn.MultiheadAttention` with
   `batch_first=True` for the cross-attention block; reuse the

   construction. Expose `H` (pre-pool elements) from the encoder

   sub-block, with defaults documented inline.

   integration / smoke / regression-guard checks above.
7. Run the full local test suite:
