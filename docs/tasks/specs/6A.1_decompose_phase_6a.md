## Purpose

Phase-entry decomposition for epic **6A — Structured-Product Pricing / FCN
Monetization Demo**. Per
[ADR 0011](../../decisions/0011_forward_strategy_accuracy_reliability_pricing.md),
Phase 6 connects the calibrated surface + uncertainty layer to **sell-side /
bank-style** structured-product pricing support, beginning with an FCN-like
payoff, as a **constrained demo** that propagates surface uncertainty into
fair-value intervals, sensitivities, and quote-risk diagnostics — **not** a
full production FCN pricer. This story breaks Phase 6 into atomic child
stories (6A.2+). Pure docs/planning — no pricing code, no run.

## Where this runs

**Local (Mac), CPU-only.** Docs only.

## Non-goals

- Do NOT write any pricing / payoff code (that is 6A.2+).
- Do NOT claim the model prices FCNs today or replaces a desk pricer.
- Do NOT build a rates / dividend / credit-spread / correlation / barrier
  modeling stack — those stay fixed / stubbed and labeled in the demo.
- Do NOT build a booking, hedging, or execution system.
- Do NOT adopt a retail or issuer-facing framing — the consumer is a sell-side
  desk; the operator is not issuing notes.

## Implementation steps

1. Fix the FCN-like payoff variant and the fixed-input assumptions (rates,
   dividends, funding/issuer spread, correlation/barriers held constant or
   stubbed) that bound the constrained demo.
2. Define the three demo outputs — fair-value intervals, sensitivities,
   quote-risk diagnostics — and how each consumes the surface uncertainty
   layer.
3. Define the quote cross-check protocol against professional desk quotes
   (operator's industry contacts) without committing sensitive/proprietary
   data.
4. Author the 6A.2+ child specs + a Phase-6 design ADR; add `backlog` BOARD
   rows.
