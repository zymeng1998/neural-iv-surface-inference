## Purpose

The data-layer prerequisite for the W3 conditional model. The Phase 1
`IVSurfaceDataset` yields one *point* per sample, which is correct for a
coordinate-regression MLP but wrong for a model conditioned on the observed
chain `O_t`. The conditional model needs each sample to be a **date**: a
variable-cardinality context set of observed points plus the query points to
predict. This story builds that date-grouped dataset and a `collate_fn` that
pads ragged context sets into batch tensors with a boolean padding mask, so the
2C.3 set encoder can pool over real (non-padded) elements only.

## Implementation steps

1. Write `tests/test_conditional_loaders.py` first (RED): build a tiny synthetic
   benchmark frame (a few dates, ragged observed counts), assert that:
   - each `__getitem__` returns one date's `(context, query)` with the right
     shapes and that context rows are exactly the `observed == True` rows;
   - `collate_fn` pads to `max_context` in the batch and produces a boolean
     `context_mask` whose `True` count per row equals that date's observed count;
   - padded positions are zero-filled and masked out.
2. Implement `ConditionalIVSurfaceDataset`: group the split frame by `date`;
   per date emit a context set (observed points: features `(log_moneyness, tau)`
   + observed input IV) and query points (all points, or a configurable query
   set) with `iv_clean` targets.
3. Implement `collate_conditional` (the `collate_fn`): pad ragged context sets,
   build `context_mask`, stack queries/targets (queries can also be ragged →
   pad + `query_mask`).
4. Export both from `data/__init__.py`. Run tests (GREEN), refactor.
5. Run the PMR pre-push gate; update data lineage + progress log.
