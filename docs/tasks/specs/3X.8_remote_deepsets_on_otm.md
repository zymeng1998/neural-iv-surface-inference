## Purpose

Retrain the Phase 2D **DeepSets / mean-pool conditional** family on
`random40_noiselow_otm` (D2). This is the neural baseline anchor for the
architecture narrative: *DeepSets mean-pool decoder → diagnosed
locality bottleneck → ANP cross-attention*. Without DeepSets-on-OTM the
clean comparison cannot say whether the DeepSets→ANP gap survives the
data correction (Q5 robustness question). Covers both the single 2D.7
equivalent and the K=5 ensemble 2D.8 equivalent.

## Where this runs

**Remote (RunPod), GPU pod.** Sequential trainings. Checkpoints stay
Pod-side; manifests + curves + per-row predictions pulled back.

## Compute requirements

- **Locale:** remote (RunPod)
- **Hardware class:** single GPU (2D.7/2D.8 tier — RTX 4090 / A4500 / A40)
- **Approx. VRAM:** ~6–10 GB
- **Approx. wall time:** single heads ~45–60 min each; K=5 ensemble
  ~4–5 h → **~6–7 h total** if all heads + ensemble run sequentially.
  (If the original 2D.7 used only gaussian+quantile+point, match that;
  the ensemble is the dominant cost.)
- **Disk — local committed artifacts:** manifests + curves + predictions
  ~30 MB per run (gitignore large prediction parquets)
- **Disk — remote working set:** ensemble checkpoints ~5×300 MB + single
  ~300 MB each → **allocate ≥ 8 GB free beyond the OTM data**
- **Notes:** the K=5 DeepSets ensemble is ~5 h of the GPU budget. If the
  operator later wants to trim the GPU bill, the single 2D.7-equiv is
  the load-bearing architecture anchor; the ensemble adds reliability-
  layer completeness. Default per D2: run both.
