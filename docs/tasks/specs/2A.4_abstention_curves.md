## Purpose

Implement the abstention / selective-prediction layer of W1: the risk–coverage
curve (error vs retained fraction as the abstention threshold sweeps) and
high-confidence MAE on the retained subset. Roadmap W1 names "abstention curves
(error vs coverage as the abstention threshold varies)" and "high-confidence MAE
(error on the retained, non-abstained subset)" as required metrics. This is the
measurement that later lets W5 justify an `abstain_flag`. Split from 2A.3
because it produces a *curve* (a sweep) rather than scalar metrics, and has a
distinct artifact shape.

## Non-goals

- Do NOT pick or hard-code an abstention threshold / policy — that is W5 (2D).
- Do NOT build the end-to-end runner or write CSV/figure artifacts to disk —
  the runner (2A.5) owns persistence; this story returns curve data structures.
- Do NOT consume real model uncertainty; operate on supplied arrays.

## Implementation steps

1. Implement `risk_coverage_curve(abs_error, confidence, n_points) ->`
   arrays of `(coverage_fraction, retained_mae)` as the abstention threshold
   sweeps from "keep all" to "keep most-confident only". Return as a typed
   structure (dataclass or DataFrame).
2. Implement an aggregate scalar: `area_under_risk_coverage` (lower is better)
   for compact model comparison.
3. Confirm the curve's "keep-all" endpoint equals overall MAE and is monotone
   non-increasing under perfectly-ranked confidence (sanity invariant).
4. Unit-test with synthetic data where confidence perfectly ranks error
   (curve must be monotone decreasing) and where confidence is random (curve
   ≈ flat at overall MAE).
