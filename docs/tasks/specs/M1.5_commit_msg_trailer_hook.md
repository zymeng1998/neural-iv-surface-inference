## Purpose

When a commit is detected as agent-driven, require a
`Co-authored-by: <Agent> <email>` trailer naming the agent. Creates an
auditable, `git log --grep`-queryable record of which agent did what
across the lifetime of the repo.

This conflicts with the user-level "attribution disabled" preference;
ADR 0007 documents the override.

## Scope contract (atomic story)

- **One question:** does the hook block agent-driven commits missing a
  `Co-authored-by:` trailer, and pass through human-driven commits
  unchanged?
- **One artifact bundle:** trailer-check script, commit-msg hook,
  installer update, tests.
- **One acceptance check:** synthetic env where `CLAUDECODE=1` set →
  missing trailer fails; trailer present → passes; no env vars set
  → passes (human commit).

## Dependencies

- M1.4 `done` (extends the installer; mirrors M1.3/M1.4 conventions).

## Agent-detection rules

The hook treats the commit as agent-driven if **any** of:

- `CLAUDECODE=1` set (Claude Code session)
- `CURSOR_TRACE_ID` non-empty (Cursor agent)
- `CODEX_*` / `AIDER_*` env vars present (future-proofing)

The set is configurable at the top of `check_commit_trailer.py` so
new agents can be added in one place.

## Trailer requirement

The commit message must contain at least one line matching:

```
^Co-authored-by: <Name> <email>$
```

The agent name in the trailer should match the detected agent
(`Claude` / `Cursor` / `Codex` / `Aider`), but the script enforces only
*presence*, not the agent identity — to avoid false negatives across
SDK versions.

## Waiver format

```
WAIVE_TRAILER="<reason>"
```

Bypasses the check; logged to stderr (no audit line — commits aren't
specs). Intended for one-off rebases / fixups.

## Non-goals

- Enforcing trailer content matches the detected agent.
- Adding the trailer automatically (that is the agent's responsibility).
- Blocking commits made directly by the human operator.

## Compute requirements

- **Locale:** local
- **Hardware class:** none
- **Approx. wall time:** ~30 min
- **Disk:** ~3 KB committed

## Implementation steps

1. Write `scripts/check_commit_trailer.py` (takes commit-msg file path
   as `argv[1]`, exit 0 pass / 1 fail).
2. Write `scripts/hooks/commit-msg` invoking the script.
3. Update `scripts/install_hooks.sh` to also install commit-msg.
4. Tests in `tests/test_check_commit_trailer.py`: human commit (pass),
   agent commit + trailer (pass), agent commit no trailer (fail),
   agent commit + waiver (pass).

## Acceptance criteria

- [ ] `pytest tests/test_check_commit_trailer.py` passes.
- [ ] After `bash scripts/install_hooks.sh`, an agent-detected commit
      without trailer is blocked; with trailer passes.
