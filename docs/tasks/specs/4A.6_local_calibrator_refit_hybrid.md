## Purpose

Re-fit the Phase 2D calibrator on the **summed hybrid** (`σ̂ = rbf_pred +
f_θ`) val predictions — the 4A.4 gaussian/quantile heads + the 4A.5 ensemble
disagreement — producing `artifacts/calibration/4A6_hybrid.json`, the
calibrator the 4A.7 decision-layer eval consumes. Mirrors 3X.11 / 3B.6 /
2D.4: no change to the calibration recipe, only the input prediction files
(now the hybrid, not pure-neural).

## Where this runs

**Local (Mac), CPU-only.** Reads the val parquets pulled back by 4A.4 +
4A.5.

- **One question:** what temperature / ensemble-scale / fusion the
  calibrator fits on the hybrid val predictions to hit ~0.90 coverage, and

  `artifacts/calibration/4A6_hybrid.json` + tests.

  hi-conf MAE < no-abstention MAE; JSON carries the fitted params + input
  bundle hashes.
