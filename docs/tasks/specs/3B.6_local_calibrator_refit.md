## Purpose

Re-fit the 2D.4 calibrator on the ANP architecture's cached val
predictions, producing the calibrator JSON that the 3B.7 decision-
layer runner consumes. Parallels 2D.4 directly: same fusion formula,
same temperature-scaling / split-conformal paths, same `Calibrator`
class, same `CalibratedConditionalPredictor` wrapper — only the
input bundle changes (3B.4 gaussian / quantile val predictions +
3B.5 ensemble disagreement + 2B.2 masking sensitivity on the ANP
checkpoints).

Local-only. CPU-only. No Pod time.

## Scope contract (atomic story)

- **One question:** what calibrator parameters (`T` for the gaussian
  head; split-conformal offset for the quantile head; monotone
  disagreement→sigma mapping) bring the ANP architecture's empirical
  coverage to within ±2 pp of the nominal 0.90 on the val fold?
- **One artifact bundle:**
  `artifacts/calibration/3B6_anp.json` (the fit calibrator) +
  `configs/calibration_3B6_anp.yaml` (the fit recipe). Same schema as
  2D.4's calibrator JSON.
- **One acceptance check:** calibrated coverage on the val fold is
  within ±2 pp of 0.90; calibrated high-confidence MAE on val is
  strictly below no-abstention val MAE on the same predictions
  (sanity check of the fusion).

## Files likely to touch

### New

- `configs/calibration_3B6_anp.yaml` — clones the 2D.4 calibration
  config; points the input paths at the 3B.4 / 3B.5 bundles:
  ```yaml
  calibration:
    target_coverage: 0.90
    inputs:
      gaussian_val_predictions:
        artifacts/runs/3B4/gaussian/val_predictions.csv
      quantile_val_predictions:
        artifacts/runs/3B4/quantile/val_predictions.csv
      ensemble_val_predictions:
        artifacts/runs/3B5/val_predictions.csv
      masking_sensitivity:
        # produced inline from the 3B.4 gaussian checkpoint via
        # the existing 2B.2 adapter; cached to artifacts/runs/3B4/.
        derive_from: artifacts/runs/3B4/gaussian/checkpoints/<final>.pt
    output:
      calibrator_path: artifacts/calibration/3B6_anp.json
  ```
  All numerical hyperparameters (fusion weights, conformal `alpha`)
  inherit from 2D.4 unless an explicit override is documented in the
  journal entry.
- `tests/test_calibration_anp.py` — runs the fit on a tiny synthetic
  predictions bundle (in-test fixture), asserts:
  - Calibrator JSON serializes / round-trips.
  - Fit `T` is finite and positive.
  - Split-conformal offset is finite.
  - `CalibratedConditionalPredictor.predict(...)` wraps a
    synthetic ANP-loaded `ConditionalSurfacePredictor` and fills
    all four `PredictionResult` fields (`pred`, `uncertainty`,
    `lower`, `upper`).
