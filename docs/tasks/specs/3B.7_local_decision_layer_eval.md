## Purpose

Closing evidence story for epic 3B. Run the existing decision-layer
runner (`scripts/run_decision_layer_eval.py`, built in 2D.6) against
the ANP architecture's full predictor lineup:

- ANP calibrated conditional predictor (3B.4 gaussian head + 3B.5
  ensemble disagreement + 2B.2 masking sensitivity, fused via the
  3B.6 calibrator),
- the Phase 2D baselines re-scored on the same slice (RBF
  interpolation; Phase-1 masked MLP; point conditional; calibrated
  conditional 2D.4) for direct comparison.

Produce the W1 + W2 + decision-layer artifacts under
`results/3/spy_phase1_random40_noiselow/3b_anp/`, plus a
side-by-side comparison CSV at `…/3b_compare/comparison.csv`, write
the `experiment_journal.md` entry that closes epic 3B against the
Phase 3 acceptance bar, and append a roadmap closing addendum under
§ W11.

Local-only. Read-only on all upstream artifacts (3B.4 / 3B.5
predictions, 3B.6 calibrator JSON, 2D.9 baseline predictions). No
training, no Pod time.

## Scope contract (atomic story)

- **One question:** does the ANP architecture, with the same
  calibration / ensembling / masking-sensitivity stack as the Phase
  2D production predictor, beat RBF on test MAE by ≥ 5 % on the
  `spy_phase1_random40_noiselow` slice, while keeping calibrated
  coverage within ±2 pp of 0.90 and high-confidence MAE strictly
  below no-abstention MAE?
- **One artifact bundle:**
  `results/3/spy_phase1_random40_noiselow/3b_anp/` (W1 + W2 +
  decision-layer outputs for the ANP predictor) plus
  `results/3/spy_phase1_random40_noiselow/3b_compare/comparison.csv`
  (one row per (predictor, metric), long-format), schema-matched to
  3A.4's `3a_compare/comparison.csv`.
- **One acceptance check:** the roadmap closing addendum under
  § W11 records (i) the measured ANP test MAE, (ii) the ANP-vs-RBF
  delta as a percentage of RBF, (iii) whether the Phase 3 acceptance
  bar is met, (iv) the reliability numbers (coverage, hi-conf MAE),
  with file references back to the committed metrics CSVs.
