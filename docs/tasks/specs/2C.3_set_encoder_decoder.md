## Purpose

The core W3 architecture: the first surface model **conditional on the observed
chain**. Two `nn.Module`s:

```text
SetEncoder:        O_t (set of observed points)  -> z_t   (permutation-invariant latent)
CoordinateDecoder: (k, tau, z_t)                 -> sigma_hat
```

The set encoder is a DeepSets-style permutation-invariant network: a per-element
MLP applied to each observed point, then a **masked** pooling (mean by default)
over the real elements, yielding a fixed-size latent `z_t` regardless of how
many quotes the date has. The decoder concatenates `z_t` with a query coordinate
`(k, tau)` and predicts IV through an MLP with a softplus output (positive IV),
mirroring the baseline-MLP head. This story is pure architecture: modules +
shape and permutation-invariance tests, no training and no data I/O.

## Implementation steps

1. Write `tests/test_conditional_surface.py` first (RED):
   - `SetEncoder` output shape is `(batch, latent_dim)` for input
     `(batch, max_context, in_dim)` + `(batch, max_context)` mask;
   - **permutation invariance**: shuffling context rows (and mask together)
     leaves `z_t` unchanged within tolerance;
   - **mask invariance**: appending padded (masked-out) rows does not change
     `z_t`;
   - `CoordinateDecoder` maps `(batch, n_query, 2)` + `z_t` to
     `(batch, n_query)` with strictly positive outputs (softplus).
2. Implement `SetEncoder` (per-element MLP → masked mean pool → optional
   post-pool MLP → `z_t`) and `CoordinateDecoder` (concat broadcast `z_t` with
   query coords → MLP → softplus). Optionally a thin `ConditionalSurfaceModel`
   wrapper exposing `forward(context, context_mask, query) -> sigma_hat`.
3. Reuse the baseline-MLP block style (Linear/LayerNorm/SiLU) and weight init.
4. Run tests (GREEN), refactor. Run the PMR gate; append progress log.
