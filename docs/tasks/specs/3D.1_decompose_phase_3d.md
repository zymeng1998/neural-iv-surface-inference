## Purpose

Phase-entry decomposition story for epic **3D — Phase 3 Closing Memo
+ Re-Evaluation** under workstream **W13**. Pure synthesis on the
committed `artifacts/runs/3*/` and `results/3/` bundles produced by
3A / 3B / 3C; no new training, no new eval runs.

Mirrors story 2D.10 (Phase 2 closing memo + notebook). Produces:

- `docs/phase3_result_memo.md` (headline table of all 3A / 3B / 3C
  variants versus RBF and versus the Phase 2D close).
- `notebooks/06_phase3_results.ipynb` (regenerable from
  `scripts/generate_phase3_results_notebook.py`).
- Closing entry in `docs/experiments/experiment_journal.md`.
- **ADR 0009 — Phase 3 production predictor selection**, which locks
  the variant that becomes the new production surface inference
  predictor (or documents the absence of one if the bar was missed).
  **(Renumber note: this story originally said "ADR 0008"; that number
  is now taken by the Phase 3C microstructure-feature-set freeze
  ([ADR 0008](../../decisions/0008_microstructure_feature_set_freeze.md),
  Implemented 2026-06-14). The production-selection ADR is therefore
  **0009**.)**
  Given that all four Phase 3 gating epics (3A architecture, 3X data
  correction, 3C features) missed the ≥ 5 %-below-RBF bar on the clean
  OTM substrate, ADR 0009 is expected to record **no pure
  conditional-neural production predictor** and to lock the forward
  direction as **Phase 4 = RBF-prior hybrid / residual neural model**
  (RBF carries the local interpolation it already wins; the neural model
  learns the residual + the calibrated reliability / abstention layer).
  See roadmap §W13.
