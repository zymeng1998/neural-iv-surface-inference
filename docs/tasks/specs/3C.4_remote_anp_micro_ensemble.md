## Purpose

K=5 deep ensemble of the **ANP + `micro_v1`** point head on
`spy_phase1_random40_noiselow_otm`, mirroring 3X.10 (which mirrored
3B.5 / 2D.8). Used in 3C.5 to fit `ensemble_scale` and in 3C.6 as the
ensemble disagreement input to the calibrated production predictor.

The point head is fixed (matches 3X.10's choice; gaussian / quantile
heads do not need an ensemble in the Phase 2D / 3B / 3X production
recipe).

## Where this runs

**Remote (RunPod), GPU pod.** Sequential trainings (5 seeds), same Pod
as 3C.3 if rented in a single window.

## Scope contract (atomic story)

- **One question:** what is the ensemble test MAE, val/test
  disagreement mean (std across the 5 members), and finite-loss rate
  for the K=5 ANP+`micro_v1` point head on OTM, vs the 3X.10 OTM
  baseline (test MAE 0.01220, disagreement mean 0.00679) and the
  RBF-on-OTM floor (0.00613)?
- **One artifact bundle:** `artifacts/runs/3C4/ensemble/` mirroring the
  3X.10 / 2D.8 schema (`members.json` + per-member checkpoints + per-row
  ensemble val/test predictions).
- **One acceptance check:** all 5 members complete with finite losses;
  ensemble predictions written; disagreement > 0; manifests carry
  `feature_set=micro_v1` + per-member seeds + dataset/config/code hashes.

## Dependencies

- 3C.3 `done` (single-model point-head training validated; the same
  config skeleton + persisted z-score stats are reused).
- OTM benchmark on Pod volume (unchanged from 3X).

- Do NOT change the ensemble size (K=5) or the seed list `[101, 202,
  303, 404, 505]` — the comparison to 3X.10 / 3B.5 is the point.
- Do NOT train heads other than point.

  checkpoint (each seed is from-scratch, mirrors 3X.10's recipe).

- Do NOT modify the ANP module, encoder, or any loader (3C.2 is the
  only feature-side change).

## Implementation steps

1. Confirm 3C.3 `done` and on Pod's checkout of `main`.
2. Clone the 3X.10 ensemble config; set `data.feature_set: micro_v1`;
   confirm `seeds: [101, 202, 303, 404, 505]` and `head.kind: point`.
3. Run all 5 members sequentially (mirrors 3X.10).
4. Aggregate per-row predictions across members → ensemble mean +
   per-row disagreement (std).
5. Pull manifest + members.json + ensemble predictions to local.
6. Append journal entry with ensemble test MAE, disagreement,
   3C-vs-3X.10 delta.
7. PMR gate dry-run; flip BOARD → `in_review`.
