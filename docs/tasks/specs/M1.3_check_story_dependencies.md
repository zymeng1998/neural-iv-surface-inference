## Purpose

Block any push that touches a story spec whose declared `Dependencies:`
list contains a story not yet `done` on the BOARD. Allow override with
an explicit env-var waiver that writes an audit line.

## Scope contract (atomic story)

- **One question:** does the gate correctly identify "story X depends
  on Y, Y is not `done`", block the push, and allow override only via
  `WAIVE_DEPS="..."`?
- **One artifact bundle:** the gate script, install script, pre-push
  shim that orchestrates PMR + dep gate, tests.
- **One acceptance check:** synthetic test repo + spec where dep is
  `in_review` → push blocked; with `WAIVE_DEPS="reason"` → allowed +
  audit line appended to spec.

## Parsing contract

A spec is recognised by being a file under `docs/tasks/specs/*.md`
with a YAML front-matter block. The front-matter must declare:

- `id: <STORY_ID>` (e.g. `3X.4`)
- `status:` (one of the legend values)

Dependencies are parsed from the spec body's `## Dependencies` section,
specifically lines of the form `- <STORY_ID> ...` (story IDs match
the regex `[0-9]+[A-Z]+\.[0-9]+` or `M[0-9]+\.[0-9]+`). The phrase
`` `done` `` next to an ID is the canonical mark.

BOARD status is the source of truth — the script greps
`docs/tasks/BOARD.md` for `| <ID> |` rows.

## Waiver format

```
WAIVE_DEPS="3X.2:in_review:operator approved out-of-order start"
```

Comma-separated for multiple. On waiver, the script appends one line
to the touched spec's last checkpoint block:

```
- DEP WAIVER (YYYY-MM-DDTHH:MM:SS-04:00): 3X.2 in_review → bypassed (operator approved out-of-order start)
```

## Implementation steps

1. Write `scripts/check_story_dependencies.py` mirroring the
   `pmr_prepush_gate.py` UX (argparse `--verbose --dry-run`, exit
   codes 0 pass / 1 fail).
2. Write `tests/test_check_story_dependencies.py` using `tmp_path`
   git repos + synthetic BOARD + specs. Cover: no deps (pass), all
   deps done (pass), dep in_review (fail), dep in_review +
   waiver (pass + audit line), malformed spec (fail loudly).
3. Write `scripts/hooks/pre-push` that runs PMR gate then dep gate
   (both must pass).
4. Write `scripts/hooks/pre-commit` (empty stub for now;
   M1.4 will use it).
5. Write `scripts/install_hooks.sh` — copies from
   `scripts/hooks/*` into `.git/hooks/*`, chmod +x.
6. Add a "First-time setup" line to README.md pointing at
   `bash scripts/install_hooks.sh`.

## Acceptance criteria

- [ ] `pytest tests/test_check_story_dependencies.py` passes.
- [ ] `python3 scripts/check_story_dependencies.py --verbose --dry-run`
      against current repo passes (or fails with a clear message
      identifying the offending spec/dep).
- [ ] `bash scripts/install_hooks.sh` installs pre-push + pre-commit
      with execute bit set.
- [ ] After install, `git push` runs both PMR gate and dep gate.
