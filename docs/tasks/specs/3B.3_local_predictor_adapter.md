## Purpose

Wire the ANP `ConditionalSurfaceModel` (3B.2) into the existing
`Predictor` surface so the W1 evaluator (`scripts/run_uncertainty_eval.py`),
the W2 diagnostics, and the W5 decision-layer runner consume it
*without code changes* — same `PredictionResult` shape, same call
signature, same artifact columns. The existing
`ConditionalSurfacePredictor` already does this for the DeepSets
baseline; 3B.3 confirms (or makes minimal additions) so that the same
adapter loads either decoder kind from its config + checkpoint.

Local-only. No training. No Pod time.

## Scope contract (atomic story)

- **One question:** does the existing
  `ConditionalSurfacePredictor.from_checkpoint(...)` correctly load
  and serve an ANP-decoder checkpoint and produce a `PredictionResult`
  whose columns / shapes match the DeepSets baseline's bit-for-bit
  (modulo the prediction values themselves)?
- **One artifact bundle:** the adapter touch-ups (if any) + the
  parity test. No model training, no Pod artifacts.
- **One acceptance check:** parity test passes on a tiny synthetic
  checkpoint of each `decoder_kind`, with all four
  `PredictionResult` fields (`pred`, `uncertainty`, `lower`, `upper`)
  present and shape-equal across kinds.

## Dependencies

- 3B.2 `done` — `ConditionalSurfaceModel(decoder_kind="anp")` must

- Existing `ConditionalSurfacePredictor` /

## Files likely to touch

### New

- `tests/test_anp_predictor_adapter.py` — parity test:
  - Construct a tiny `ConditionalSurfaceModel(decoder_kind="deepsets")`
    and a tiny `ConditionalSurfaceModel(decoder_kind="anp")` on
    matched synthetic data; serialize each to a temp checkpoint.
  - Load each via `ConditionalSurfacePredictor.from_checkpoint(...)`
    and call `.predict(df_test)` on a synthetic
    `(date, k, τ, iv_input, …)` dataframe.
  - Assert: both calls return a `PredictionResult` with the same
    column set, same row order (== `df_test` row order; non-shuffled
    contract from 2C.5), and the same dtypes per column. Assert the
    four fields (`pred`, `uncertainty`, `lower`, `upper`) are either
    both `None` or both populated, consistent with the configured
    `head.kind`.

    `uncertainty == sigma_hat > 0` and `lower < pred < upper`
    componentwise on the ANP-loaded predictor.

## Non-goals

- Do NOT introduce a new `Predictor` class. `ANPConditionalPredictor`
  is **not** to be created — the existing
  `ConditionalSurfacePredictor` handles both decoder kinds, since the
  difference is internal to `ConditionalSurfaceModel`.
- Do NOT modify `EnsembleConditionalPredictor` or
  `CalibratedConditionalPredictor`. They already wrap any underlying
  `ConditionalSurfacePredictor`; once 3B.3 confirms parity, those
  composers inherit the new decoder kind for free. (3B.5 / 3B.6
  verify this in their integration scope.)
- Do NOT train any model on AV. Synthetic checkpoints only.
- Do NOT touch `scripts/run_uncertainty_eval.py` or any 2D runner
  script — parity is verified at the adapter boundary.
- Do NOT touch any 3A / 3C / 3D file.
