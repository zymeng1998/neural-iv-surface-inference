## Purpose

Phase-entry decomposition story for epic **3C — Feature &
Inductive-Bias Expansion** under workstream **W12**. Two orthogonal
directions were originally on the table; 3C.1 picks scope based on the
post-3X evidence.

## Decisions locked into this decomposition (operator-confirmed 2026-06-02)

These supersede the pre-3X scaffold (2026-05-27) and refine ADR 0008.

- **Track scope — `micro_v1` only.** Ship the **microstructure feature
  expansion only** in 3C. The SVI / SSVI parameterized-head track is
  **deferred** (separate epic if/when 3C lands). Rationale: §W11.5
  closing addendum recommended feature/inductive-bias expansion; the
  microstructure track is cheaper, has lower under-fitting risk, and
  isolates a single hypothesis (encoder gets per-quote reliability
  signal → can downweight unreliable quotes when forming `z_t`). If
  `micro_v1` does not narrow the gap, the SVI head is opened as a
  fresh epic with attribution untangled from microstructure.
- **Feature set — full AV-native (`micro_v1`).** Six new per-quote
  fields appended to the existing 3-tuple per
  [ADR 0008](../../decisions/0008_microstructure_feature_set_freeze.md):
  `bid`, `ask`, `bid_ask_spread_rel`, `volume`, `open_interest`,
  `put_call_indicator`. Rationale: full set keeps the head ablation
  clean — no "but did raw price level matter?" follow-up question.
  All six are AV-native (no new ingest); the 3C.1 non-goal blocks
  `vix`, `realized_vol`, `days_to_earnings_or_dividend`.
- **Head sweep — all three heads.** Mirror 3X.9 (gaussian / quantile /
  point). Rationale: matches the Phase 3 evidence-discipline pattern;
  enables `3C.7` to produce 3X.13-style comparison tables; head
  ablation is observable without re-runs.
- **Substrate — `spy_phase1_random40_noiselow_otm` only.** Same matched
  substrate as 3X (per §W11.5 close-out: 3C reopens on the clean OTM
  substrate). No 11-variant fan-out (deferred robustness study from
  §W11.5 future-work block carries through).
- **Q2 invariant carries forward.** Decision-layer thresholds are
  **held constant** against 3X.12 in 3C.6; no decision-config retune
  inside the feature-level study.
- **ADR renumbering.** The pre-3X 3C.1 stub referred to "ADR 0006"
  (microstructure) and "ADR 0007" (SVI). Both numbers are now taken
  (ADR 0006 = duplicate-coordinate correction, ADR 0007 = multi-agent
  handoff). This decomposition uses **ADR 0008** for the microstructure
  feature freeze and reserves **ADR 0009** for the deferred SVI head
  (only written if/when an SVI epic opens).
- **No-overclaim guardrail (carried from 3X).** All claims are scoped
  to the matched `random40_noiselow_otm` substrate only. No 11-variant
  robustness claim. This guardrail propagates to 3C.7 and 3C.8.
- **Phase 4 fallback unchanged.** If 3C closes without meeting the
  Phase 3 bar (≥ 5 % below RBF on test MAE), 3D synthesises and Phase
  4 (RBF-prior + neural-residual hybrid) opens per
  [ADR 0004](../../decisions/0004_phase3_accuracy_push_framing.md). 3C
  does NOT pre-empt 3D — even if `micro_v1` clears the bar, 3D writes
  the full Phase 3 closing memo (Q3 carried from 3X).
