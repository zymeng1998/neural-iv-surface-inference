> `file_scope` is a hard contract. M1.2 ships **before** the gates
> (M1.3–M1.5) so that any agent reading `AGENTS.md` next session
> already knows the gates exist.

## Purpose

Give every coding agent a single, project-scoped, ≤120-line entry
point that routes them to the right doc for the task at hand — instead
of letting them grep the whole `docs/` tree on cold start.

## Scope contract (atomic story)

- **One question:** can a cold agent (Cursor, fresh Claude session)
  read one file (≤120 lines) and know how to pick up the next story
  without reading any other doc broadly?
- **One artifact bundle:** `AGENTS.md`, `.cursor/rules/000-bootstrap.mdc`,
  CLAUDE.md edit.
- **One acceptance check:** `AGENTS.md` is ≤120 lines; cold-start
  prompt at its bottom is copy-pasteable; CLAUDE.md first line points
  at `AGENTS.md`; Cursor mdc has `alwaysApply: true`.

## Dependencies

- M1.1 `done` (ADR + epic registered).

See `file_scope`.

## Design constraints

- `AGENTS.md` is a **router**, not a manual. Every line either (a)
  routes to one file, or (b) states a rule that is also script-enforced.
- No re-stating of content that lives in `CLAUDE.md`, ADRs, or
  `docs/agent_bootstrap/`. Point, don't copy.
- Cold-start prompt at the bottom must be agent-agnostic
  (works for Cursor, Claude Code, Codex, Aider).

## Non-goals

- Writing the gates (M1.3–M1.5).
- Promoting any rule to `~/.claude/`.

## Compute requirements

- **Locale:** local
- **Hardware class:** none
- **Approx. wall time:** ~30 min
- **Disk:** ~10 KB committed

## Implementation steps

1. Draft `AGENTS.md` (router structure, ≤120 lines).
2. Add `.cursor/rules/000-bootstrap.mdc` (`alwaysApply: true`, ≤10 lines).
3. Edit `CLAUDE.md`: prepend a 3-line directive pointing at `AGENTS.md`;
   leave the rest as Claude-specific overrides.
4. Verify line counts.
5. PMR gate dry-run.

## Acceptance criteria

- [ ] `AGENTS.md` exists and is ≤120 lines.
- [ ] `.cursor/rules/000-bootstrap.mdc` exists with `alwaysApply: true`.
- [ ] CLAUDE.md begins with a directive to read `AGENTS.md`.
- [ ] Cold-start prompt block appears at end of `AGENTS.md`.
- [ ] PMR gate dry-run passes.

## Rollback notes
