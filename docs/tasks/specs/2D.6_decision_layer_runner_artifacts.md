## Purpose

Build the **runner skeleton** that will ultimately produce the closing
end-to-end evidence for epic 2D. The runner wires the W1 uncertainty
evaluator (2A), the W2 risk-flag diagnostics (2B), the calibrated conditional
predictor (2D.4), and the decision layer (2D.5) into a single command. This
local story lands the script, its config schema, the report-table
additions, the artifact-directory layout under `results/2D/`, and a fully
green **synthetic smoke** against a tiny synthetic dataset + a dummy
predictor — proving that every expected file is written and every code path
is exercised before the Pod is spun up.

The matching **remote** end-to-end execution on the AV benchmark — which
actually closes epic 2D acceptance §5 (decision-grade outputs) and §6
(calibration demonstrated) — is **story 2D.9**.

## Where this runs

**Local (Mac) only.** Synthetic dataset, dummy `Predictor` and dummy
`no_arb_risk_flags`, CPU-only run, no AV data, no Pod time. Story ships when
the synthetic smoke produces every expected file under
`results/2D/synthetic/<dummy_predictor>/`.

## Implementation steps

1. Define `configs/decision_layer_eval.yaml` schema: list of
   `(dataset, predictor, calibrator_path?)` rows + global thresholds path
   pointing at `configs/decision_layer.yaml`.
2. Write `scripts/run_decision_layer_eval.py`:
   - Load config; iterate over `(dataset, predictor)` pairs.
   - For each pair: build the predictor through the existing adapter
     interface, run the W1 evaluator, run the W2 diagnostics, then apply
     the 2D.5 decision layer.
   - Per-pair outputs (CSV + figures) written under
     `<results_root>/<dataset>/<predictor>/`:
     - per-row predictions+decisions CSV,
     - metrics summary CSV,
     - region-level tradability table,
     - abstention curve PNG,
     - calibration plot PNG.
   - Top-level comparison table at `<results_root>/comparison_summary.csv`
     with columns:
     `dataset, predictor, test_mae, hi_conf_mae, coverage_90, mean_width,
     abstain_rate, mean_tradability, n_forbidden_flag_violations`.
   - `--results-root` flag so the synthetic smoke writes to a temp dir, not
     `results/2D/`.
3. Add a tiny `tests/test_decision_layer_runner.py` synthetic smoke that:
   - Builds a synthetic surface and a deterministic dummy predictor (mean +
     a synthetic uncertainty signal) and dummy `no_arb_risk_flags`.
   - Invokes the runner pointed at a temp dir.
   - Asserts every expected file exists, the `comparison_summary.csv`
     parses with the documented columns and is non-empty, and per-pair
     CSVs are shape-aligned with the input.
4. Add report-table helpers in `eval/report.py` only if the existing
   helpers from 2A.5 / 2B.5 do not already cover the decision-layer
   summary tables.
5. Update `docs/logs/progress_log.md`.
