## Purpose

Run the **existing 4A residual-hybrid checkpoint** (gaussian production head;
point ensemble for disagreement) **forward** over each regime × rung's sparser
observed context, sum the residual prediction with that rung's RBF (from 4B.3)
to form `σ̂ = RBF_rung + f_θ(sparse context)`, and emit per-query predictions.
This is the **eval-time** half of the staged design: **no retraining** — the
checkpoint trained on full context is stress-tested on sparser context, which
is the explicit fairness caveat to document (a clearly-labeled robustness read,
not a fully fair retrain — that escalation is the conditional 4B.7).

## Where this runs

**Remote (RunPod).** Requires the **4A checkpoint** on the Pod volume (the
gaussian hybrid from 4A.4 + the point ensemble from 4A.5). Forward passes are
cheap (small model); the model can run on a modest GPU or CPU — the gate is
checkpoint availability, not FLOPs.

## Dependencies

- 4B.3 `done` (swept RBF/context inputs materialized).
- 4A.4 `done` (gaussian hybrid checkpoint) + 4A.5 `done` (point ensemble).

## Scope contract (atomic story)

- **One question:** what does the calibrated 4A hybrid predict at the fixed

## Compute requirements

- **Locale:** remote (RunPod)
- **Hardware class:** single GPU (e.g. RTX 4090 / A40) **or** CPU — small model;
  choose by what hosts the 4A checkpoint volume fastest
- **Approx. VRAM:** ~2–4 GB if GPU (forward only)
- **Approx. wall time:** ~30–60 min Pod (forward × ~15–20 regime·rung passes;
  I/O-bound on loading swept inputs)
- **Disk — local committed artifacts:** ~1–2 MB (manifest; prediction CSVs are
  gitignored, pulled for 4B.5)
- **Disk — remote working set:** reuses the 4B.3 swept parquet + the 4A
  checkpoint already on `/workspace` (exclude from sizing); ~0.5 GB scratch →
  **allocate ≥ 4 GB free**.
- **Notes:** the **only** 4B story that needs the 4A checkpoint / a Pod with the
  4A volume. Mount the volume that holds the 4A.4/4A.5 checkpoints. After this
  story the pod is terminable — 4B.5/4B.6 run fully local from cached CSVs
  (same pattern as 4A.7/4A.8).

## Implementation steps

1. Load the gaussian hybrid + point ensemble checkpoints; for each regime ×
   rung, encode the sparser context, predict the residual, add 4B.3 RBF →
   σ̂; apply the 4A.6 calibrator.
2. Emit per-query CSVs (σ̂, band, disagreement, iv_true) per rung; pull local.
3. Provenance check: dense rung σ̂ MAE == 0.006006 (±tol); commit manifest;
   append journal.
