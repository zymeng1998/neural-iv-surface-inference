## Purpose

Build the second W4 uncertainty source: a **deep ensemble** of K independently
trained conditional models (the W3 architecture from 2C, unchanged) plus an
`EnsembleConditionalPredictor` adapter that aggregates member predictions into a
single `sigma_hat = mean_k sigma_k` and a per-point disagreement signal
`disagreement = std_k sigma_k`. Independent of 2D.2 — the two stories can be
worked in parallel.

The disagreement signal is a model-disagreement uncertainty proxy. It is
*combined with* the heteroscedastic / quantile interval from 2D.2 and the
masking-sensitivity signal from 2B.2 into the calibrated `confidence_score` in
2D.4. This story stops short of fusion or calibration.

## Where this runs

**Local (Mac) only.** `scripts/run_ensemble_train.py`, the
`EnsembleConditionalPredictor` adapter, the `members.json` manifest schema,
and adapter unit tests against a tiny dummy 2-member ensemble with
deterministic mock outputs. Plus a single 2-member synthetic-smoke train
end-to-end on the on-the-fly synthetic dataset. No AV data, no Pod time. The
matching **remote** full K-seed ensemble train on AV is **story 2D.8** — do
not run it here.

## Non-goals

- Do NOT change the model architecture or training loop — pure replication.
- Do NOT calibrate disagreement into probability; that lives in 2D.4.
- Do NOT introduce a heteroscedastic / quantile head — that is 2D.2.
- Do NOT alter `Predictor`, `PredictionResult`, or W1/W2 evaluators.
- Do NOT bundle multiple seeds into a single training run — each member is a
  full independent train so disagreement reflects real initialization and SGD
  variance.
- Do NOT run the full K-seed ensemble on the AV benchmark. The Pod-bound
  full-data ensemble training pass is **story 2D.8** and is explicitly out
  of scope here.

## Implementation steps

1. Add `ensemble: {size: 5, seeds: [101, 202, 303, 404, 505]}` to
   `configs/conditional.yaml` (defaults; overridable on the CLI).
2. Write `scripts/run_ensemble_train.py`: load the config, iterate over seeds,
   re-invoke the existing 2C.4 training entrypoint per seed, and write each
   member checkpoint to `checkpoints/conditional/ensemble/seed_{seed}/` with a
   `members.json` manifest at the parent directory listing seed, config hash,
   final val loss, and checkpoint path per member.
3. Implement `EnsembleConditionalPredictor` in `eval/adapters.py`: takes the
   manifest path, lazy-loads members, and exposes `predict(df) ->
   PredictionResult` with:
   - `sigma_hat`: per-member mean
   - `uncertainty`: per-member std (raw disagreement, **uncalibrated**)
   - `lower`, `upper`: left `None` (no calibrated interval yet)
4. Unit tests on a tiny dummy ensemble (≥2 mock members with deterministic
   outputs) verifying:
   - `sigma_hat` equals the arithmetic mean of member outputs
   - `uncertainty` equals the population std (or sample std — pick one and
     document)
   - shape alignment with input `df`
   - manifest with a missing member checkpoint raises a clear error
5. Synthetic smoke: train an ensemble of size 2 on the synthetic dataset used
   by 2C.4, load it through the adapter, and confirm non-zero disagreement on a
   small held-out batch.
6. Update `docs/logs/progress_log.md`.
