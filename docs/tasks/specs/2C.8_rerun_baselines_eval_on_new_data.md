## Purpose

Re-derive the Phase 1 baseline results (interpolation floor + masked MLP) **and**
the Phase 2A (W1 uncertainty-eval) + Phase 2B (W2 structure-diagnostics) result
artifacts against the new Alpha Vantage dataset produced by 2C.7. Without this
rerun, the Phase 1 comparison numbers in the result memo (interp test MAE 0.0687,
MLP test MAE 0.0967) and the W1/W2 artifacts are stale evidence — they describe
a dataset that no longer exists on disk. This story refreshes those artifacts
so 2C.4/2C.5 (conditional model) compares against a like-for-like floor.

This is **remote-only** — the rebuilt benchmark Parquet lives on the Pod. The
rerun uses the existing scripts (`run_baseline.py`, `run_uncertainty_eval.py`,
`run_structure_diagnostics.py`) unchanged.

## Implementation steps

1. **Confirm the Phase 1 baseline runner accepts the new benchmark Parquet
   unchanged** — schema and naming were preserved by 2C.7.
   ```
   python3 scripts/run_baseline.py --config configs/baseline.yaml \
       > /tmp/baseline.log 2>&1; tail -30 /tmp/baseline.log
   ```
2. **Re-run W1 uncertainty evaluation** on the same predictor set
   (interpolation + MLP):
   ```
   python3 scripts/run_uncertainty_eval.py ... \
       > /tmp/w1_eval.log 2>&1; tail -30 /tmp/w1_eval.log
   ```
3. **Re-run W2 structure diagnostics** on the same surfaces:
   ```
   python3 scripts/run_structure_diagnostics.py ... \
       > /tmp/w2_diag.log 2>&1; tail -30 /tmp/w2_diag.log
   ```
4. **Compare to the historical (Dubach-era) numbers**: build a small side-by-side
   table (overall MAE, observed/unobserved split, short-maturity/wing regions,
   structural violation counts, masking stability) — captured in
   `experiment_journal.md` and the refreshed result memo.
5. **Commit refreshed artifacts** under `artifacts/results/` and the
   `best_mlp.pt` checkpoint. Update the memo's numbers with a clear
   "Alpha Vantage rerun" callout that preserves the prior numbers as a
   contrast.
6. **PMR thoroughness**: update progress log, experiment journal, and run the
   PMR gate dry-run.

## Rollback notes

Re-runs are non-destructive to data (the new benchmark Parquet is the input,
not the output). Artifacts are versioned via `git` — to undo, revert the
`artifacts/results/` and memo commits. The MLP checkpoint is overwritten by
the new fit; if the old (Dubach-era) checkpoint is wanted, it must be
preserved out-of-band before the rerun (operator's call).
