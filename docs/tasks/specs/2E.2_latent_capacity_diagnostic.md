## Purpose

Answer a single question on the **existing** production 2D.7 gaussian
checkpoint: **how much of the W3 `SetEncoder`'s `latent_dim=64` is actually
carrying signal, and is that signal concentrated in a few directions or
spread evenly across dimensions?**

The output should be specific enough to support a follow-up decision: e.g.
"effective rank is ~3 and top-2 PCs explain 90% of prediction variance →
the latent is over-parameterized" vs "effective rank is ~58 and per-dim
ablation shows every dim contributes within a factor of 2 → the latent is
saturated and we should *expand*, not shrink".

This is the **diagnostic-only** story. The downstream `latent_dim` sweep
that this story may motivate is split out as
[`2E.3 latent_dim sweep`](2E.3_latent_dim_sweep.md) per the atomic-story
rule — its scope (which widths to sweep, or whether to sweep at all) is
deliberately deferred until 2E.2's findings are in.

Two complementary lenses, both run on the same captured `Z`:

- **Spectral lens (PCA on `Z`).** Effective rank, stable rank, k95, k99,
  per-PC variance share, PC loadings. Answers "how many directions does
  `Z` actually span and which raw dims compose them?"
- **Causal lens (ablation on the decoder).** Per-dim and per-PC zero-out
  ablations measured by ΔNLL on val. Answers "how much does each
  dim / each PC actually move the prediction?"

The spectral lens describes how `Z` is *distributed*; the causal lens
describes how `Z` is *used*. A dim can be high-variance but irrelevant to
the decoder, or low-variance but high-leverage — we need both to make a
defensible width call.

## Implementation steps

### Spectrum (pure numpy, local-testable)

1. **`diagnostics/effective_rank.py`** — frozen dataclass `RankReport`
   with fields:
   - `singular_values: np.ndarray` (shape `[latent_dim]`)
   - `eff_rank_entropy: float` = `exp(H(p))` where
     `p_i = σ_i² / Σ_j σ_j²` (Shannon entropy in nats over the variance
     distribution — use variances, not raw σ, so the metric is invariant
     to a sign / scaling convention)
   - `stable_rank: float` = `(Σσ_i²) / σ_max²` (Frobenius² / spectral²;
     the standard "stable rank" definition)
   - `k95: int`, `k99: int` — smallest `k` with cumulative variance
     (`Σ_{i≤k} σ_i² / Σ_j σ_j²`) ≥ 0.95 / 0.99
   - `variance_ratio: np.ndarray` — per-PC `σ_i² / Σ_j σ_j²`
   - `cumulative_variance: np.ndarray`
   - `dead_pcs: int` = count of PCs with `variance_ratio < 1e-4`
   - `pc_loadings: np.ndarray` (shape `[latent_dim, latent_dim]`) —
     right singular vectors (columns are PCs in the raw-dim basis);
     enables "which raw dims compose PC k"
   Provide `analyze(Z: np.ndarray) -> RankReport` that mean-centres `Z`,
   runs `np.linalg.svd(Z_c, full_matrices=False)`, and populates the
   dataclass. PEP-8, type-annotated, no `print()` (use `logging`).

### Capture (torch, remote)

2. **`diagnostics/latent_probe.py`** — register a forward hook on the
   final `nn.Linear` of `SetEncoder.post_mlp` (verify the exact attribute
   path against current `conditional_surface.py` before writing the
   hook). `extract_latents(model, loader, device) -> torch.Tensor` runs
   the model in `eval()` mode under `torch.no_grad()` over the supplied
   loader, captures the post-MLP linear output (`z_t` before any
   downstream concat), stacks into `[N, latent_dim]`, detaches, moves
   to CPU, returns. Hook is removed in a `try/finally`.

### Causal contribution (torch, remote)

3. **`diagnostics/contribution.py`** — three utilities, all consuming a
   loaded model + the captured per-batch `z_t` cache (or recomputed on
   the fly via the hook) and reporting val NLL:
   - `ablate_dim(model, loader, dim: int) -> float` — replaces
     `z_t[:, dim]` with its training-set mean (mean-substitution, not
     hard zero — mean-substitution removes information while preserving
     the marginal so any ΔNLL is attributable to the dim's signal, not
     to dragging the activation off-manifold). Returns val NLL.
   - `ablate_pc(model, loader, pc_idx: int, U_mean: np.ndarray,
     pc_loadings: np.ndarray) -> float` — projects each `z_t` onto the
     PC basis, replaces the `pc_idx`-th coordinate with its mean
     (typically ~0 after centring), projects back to the raw basis,
     forwards through the decoder. Returns val NLL.
   - `topk_pc_reconstruction(model, loader, k: int, U_mean, pc_loadings)
     -> float` — reconstructs `z_t` from only its top-k PCs (zero the
     remaining `latent_dim - k` PC coordinates), forwards through the
     decoder. Returns val NLL. Run for `k ∈ {1, 2, 3, 5, 8, 16, 32, 64}`
     (cap at `latent_dim`).
   Baseline NLL (no ablation) is captured once for delta computation.

4. **`scripts/run_latent_diagnostic.py`** — CLI:
   `--config <yaml> --checkpoint <path> --split val|test --out <dir>`.
   Steps:
   1. Load config; build val/test loader exactly as `train_conditional()`
      does (reuse the dataset / collation helpers it imports).
   2. Load model via `ConditionalSurfacePredictor`.
   3. `Z = extract_latents(model, loader, device)`.
   4. `report = analyze(Z.numpy())`.
   5. Baseline NLL on the split.
   6. For each `dim in range(latent_dim)`: `per_dim_ablation[dim] =
      ablate_dim(...) - baseline`.
   7. For each `pc in range(latent_dim)`: `per_pc_ablation[pc] =
      ablate_pc(...) - baseline`.
   8. For each `k` in `{1, 2, 3, 5, 8, 16, 32, 64}`:
      `topk_recon[k] = topk_pc_reconstruction(...) - baseline`.
   9. Write artifacts (see "Expected artifacts" below).
   All verbose tensor / matplotlib output redirected to `<out>/run.log`
   per `~/.claude/CLAUDE.md` §2.1; only summary scalars printed to stdout.

### Tests

5. **`tests/diagnostics/test_effective_rank.py`** — pytest, marked
   `@pytest.mark.unit`. Cases:
   - Rank-1 matrix (`Z = u @ v.T`, `N=100, d=8`) → `eff_rank_entropy`
     within `[0.99, 1.01]`, `stable_rank` within `[0.99, 1.05]`, `k95 == 1`.
   - Isotropic Gaussian `Z ~ N(0, I_d)` with `N=10_000, d=8` →
     `eff_rank_entropy` within `[7.5, 8.0]`, `k95 ∈ [7, 8]`.
   - Monotonicity: `singular_values` strictly non-increasing;
     `cumulative_variance` monotonically non-decreasing; `k95 ≤ k99`.
   - `dead_pcs` counts injected zero columns correctly.

6. **`tests/diagnostics/test_contribution.py`** — pytest, marked
   `@pytest.mark.unit`. Build a tiny torch `nn.Linear(d, 1)` decoder
   with known weights `w` and a synthetic `Z`:
   - `ablate_dim(dim=i)` ΔNLL ranks should match `|w_i| * std(Z[:, i])`
     ranking (Spearman ρ ≥ 0.95 on a 16-dim toy problem).
   - `topk_pc_reconstruction(k=d)` ΔNLL ≈ 0.
   - `topk_pc_reconstruction` is monotonically non-increasing in `k` on
     a controlled spectrum.
