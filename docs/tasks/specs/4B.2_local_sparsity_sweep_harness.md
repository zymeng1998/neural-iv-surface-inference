## Purpose

Build the **sparsity-sweep harness**: given the committed OTM benchmark, emit a
ladder of progressively sparser *observed contexts* while holding the
*query/target set fixed*, so RBF and the 4A hybrid are compared on the **same**
evaluation points as the chain they condition on thins out. The fixed-query
invariant is what makes the per-rung MAE deltas comparable (only the context
changes, not the metric's target set). This story is **code + tests only** — no
full-dataset build, no checkpoint, no GPU (mirrors 4A.2's role).

## Where this runs

**Local (Mac), CPU-only.**

## Regimes & rungs (resolved at 4B.1)

Four regimes, each a parameter of the harness (not separate stories):

1. **`fewer_quotes`** — denser→sparser random retention of observed quotes
   (e.g. retain 100 % → 75 % → 50 % → 30 % → 15 % of the observed set).
2. **`thin_wings`** — progressively drop the deepest-OTM tail quotes from the
   context (by |log-moneyness| percentile rungs).
3. **`missing_maturities`** — drop whole expirations from the observed context
   (1 → 2 → … maturities removed), calendar structure must be inferred.
4. **`combined_quotes_wings`** — joint stress: fewer quotes **and** thinned
   wings at matched rung intensities (operator-requested).

The **query/target set is identical across all rungs and regimes** (the
benchmark's labeled evaluation points); only the observed context shrinks.
