## Purpose

Remote counterpart to **story 2D.2**. Train the conditional Set-Encoder +
Coordinate-Decoder model on the Alpha Vantage benchmark with the new
predictive-interval heads landed locally in 2D.2:

- A `head.kind: gaussian` run (heteroscedastic Gaussian NLL).
- A `head.kind: quantile` run (pinball loss, default quantile triplet
  `(0.05, 0.5, 0.95)`).
- A `head.kind: point` control re-run to confirm 2C-parity on the same
  benchmark + commit (regression guard).

Produces the per-row val/test predictions, per-epoch training logs, and
final-metric summaries that downstream stories consume: 2D.4 (calibration on
cached val preds), 2D.5 (decision-layer thresholds are tuned against the
distribution of these uncertainty signals), and 2D.9 (end-to-end scoring).

## Where this runs

**Remote (RunPod) only.** GPU-heavy training over the AV benchmark already
materialized by 2C.7. Checkpoints, per-row CSVs, and run logs stay on the
Pod; only val/test prediction CSVs, training-curve summaries, and a run
manifest are pulled back to the laptop and committed.

## Implementation steps

1. On the Pod, materialize the three configs from `configs/conditional.yaml`
   with `head.kind ∈ {gaussian, quantile, point}` and identical seed + data
   + hyperparameters.
2. Run the three trainings sequentially via
   `scripts/run_conditional_2D7.sh` (or the existing 2C training entry
   point with overrides), each emitting:
   - best-val checkpoint on the Pod (kept Pod-side),
   - per-epoch `training_curve.csv`,
   - per-row `val_predictions.csv` and `test_predictions.csv` with the
     uncertainty columns appropriate to the head (Gaussian: `mu`,
     `log_sigma2`; quantile: `q_lo, q_med, q_hi`; point: `mu` only),
   - a `manifest.json` per run (config hash, git SHA, dataset version,
     final val/test MAE, wall-clock).
3. Rsync the CSVs + manifests (not the checkpoints) to
   `artifacts/runs/2D7/<head_kind>/` on the laptop.
4. Confirm point-control parity: the new `head.kind: point` run's test MAE
   matches the 2C.5-R baseline within a documented tolerance (regression
   guard); record the delta in the journal entry.
5. Append an `experiment_journal.md` entry with all three runs' headline
   metrics + paths.
6. Update `docs/logs/progress_log.md`.
7. Run the live PMR gate (this commit touches the journal).
