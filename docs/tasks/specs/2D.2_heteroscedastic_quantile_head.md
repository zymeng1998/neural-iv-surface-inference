## Purpose

Equip the Phase 2C conditional Set-Encoder + Coordinate-Decoder model with a
**predictive-interval head** so it emits a per-point uncertainty in addition to
the point IV estimate. This is the first of two independent W4 uncertainty
sources (the other is the deep ensemble in 2D.3). The head plus its training
objective are added behind a config switch so the existing 2C point training
recipe is preserved as the default.

Two interchangeable implementations are in scope (one is selected by config —
both wired, ship-quality):

- **Gaussian (heteroscedastic) head** — output `(mu, log_sigma2)`; train with
  Gaussian NLL; `lower/upper = mu ± z * sigma` at a configurable nominal level.
- **Quantile head** — output `(q_lo, q_med, q_hi)` for a configured quantile
  triplet (default `(0.05, 0.5, 0.95)`); train with pinball loss; enforce
  monotone ordering at inference.

Adapter wiring into the `Predictor` interface and calibration on a held-out fold
both belong to 2D.4 — not here. 2D.2 lands the model + training-loop changes,
emits raw (uncalibrated) uncertainty signals, and verifies them with shape /
loss / monotonicity unit tests plus a synthetic smoke train.

## Where this runs

**Local (Mac) only.** All code changes, unit tests, and three small
synthetic-smoke trains (point / Gaussian / quantile) on the on-the-fly
synthetic dataset already used by 2C.4. No AV data, no Pod time, no data
egress. The matching **remote** full-AV training pass is **story 2D.7** —
do not run it here.

## Implementation steps

1. Add a `head: {kind: point|gaussian|quantile, ...}` block to
   `configs/conditional.yaml` with default `kind: point` (the 2C recipe).
2. Extend `ConditionalSurfaceModel` (or wrap it) so the decoder emits the
   appropriate output dimensionality per head kind and `forward()` returns a
   `dict` that always includes `mu` plus optional `log_sigma2` / quantile
   tensors. `softplus` (or equivalent) on `sigma` to guarantee positivity.
3. Add `gaussian_nll_loss` and `pinball_loss` to `models/losses.py` (or a new
   `losses.py` section), each masked the same way as the existing MSE loss.
4. In `train_conditional.py`, dispatch loss + checkpointed metric per head
   kind. Keep best-val checkpointing, early stopping, seed control unchanged.
5. Add unit tests covering: output shapes per head; quantile monotonicity at
   inference (sort if necessary or assert pre-sorted); Gaussian NLL finite and
   decreasing on a 1-batch overfit; pinball loss zero at the perfect-quantile
   fixture.
6. Run the existing synthetic smoke from 2C.4 with `head.kind: point` to prove
   no regression, then run two new smokes with `gaussian` and `quantile` heads
   on the same synthetic surface; record final losses in the progress-log
   entry.
7. Update `docs/logs/progress_log.md`.

## Acceptance criteria

- [ ] With `head.kind: point` the model and training behavior are bit-for-bit
      equivalent to 2C (same losses on the seeded synthetic smoke).
- [ ] With `head.kind: gaussian` the model emits `(mu, log_sigma2)`, the
      training loss is Gaussian NLL, and the synthetic smoke loss is finite
      and decreasing over epochs.
- [ ] With `head.kind: quantile` the model emits `(q_lo, q_med, q_hi)` ordered
      at inference, the training loss is the masked pinball loss, and the
      synthetic smoke loss is finite and decreasing.
- [ ] All listed tests pass.
- [ ] PMR gate dry-run passes.

## Rollback notes

recipe. The new loss functions are pure additions; removing them only requires
deleting the new code paths. No data or schema mutated.
