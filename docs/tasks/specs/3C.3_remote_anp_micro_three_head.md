## Purpose

Retrain the end-to-end **DeepSets+ANP** conditional model on
`spy_phase1_random40_noiselow_otm` with `feature_set: micro_v1` (ADR
0008) across **all three head kinds** (gaussian / quantile / point).
Faithful head-by-head restatement of 3X.9 with the only change being
the per-quote feature tuple — same dataset, same seed, same optimizer
schedule, same `decoder_kind: anp`, same `coord_encoding.kind: raw`.
This is the headline 3C model and the input to the calibration / eval
chain (3C.5 / 3C.6).

## Where this runs

**Remote (RunPod), GPU pod.** Sequential trainings mirroring 3X.9.
Checkpoints Pod-side; manifests + curves + per-row val/test predictions
pulled back to local for 3C.5+.

## Scope contract (atomic story)

- **One question:** what is the ANP+`micro_v1` test MAE, val/test NLL,
  and quantile coverage/monotonicity on
  `spy_phase1_random40_noiselow_otm` across all three heads, and how
  do those numbers compare to the matched 3X.9 OTM baselines (test MAE
  gaussian 0.01440 / quantile 0.01175 / point 0.00987) and the
  RBF-on-OTM floor (test MAE 0.00613)?
- **One artifact bundle:** `artifacts/runs/3C3/{gaussian, quantile,
  point}/` mirroring the 3X.9 bundle schema.
- **One acceptance check:** all three complete with finite losses;
  quantile monotonic on test; manifests carry `feature_set=micro_v1`
  + per-feature z-score stats + dataset/config/seed/code hashes;
  ANP-vs-RBF and ANP-vs-ANP-baseline deltas journaled per head.

## Non-goals

- Do NOT modify `ANPDecoder`, `SetEncoder`, `ConditionalSurfaceModel`,
  or any loader — every change is in 3C.2 (already shipped).
- Do NOT warm-start from any dirty or OTM `minimal`-feature checkpoint
  (the encoder's input-projection layer has a different `in_features`;
  weight loading would silently truncate). From-scratch only, mirrors
  3X.9's D8.
- Do NOT run on any benchmark other than `random40_noiselow_otm`.
- Do NOT change the decoder, the coordinate encoding, the head menu,
  or the seed / hparams.
- Do NOT train an ensemble here (that is 3C.4).
- Do NOT re-fit the calibrator here (that is 3C.5).
- Do NOT make Phase 3 bar pass/fail claims based on raw test MAE
  alone — the bar is adjudicated end-to-end via 3C.6.

## Compute requirements

- **Locale:** remote (RunPod)
- **Hardware class:** single GPU (3X.9 tier — RTX A4500 / 4090 / A40)
- **Approx. VRAM:** ~8–14 GB (ANP cross-attention + the 9-dim context
  adds a small parameter bump in `SetEncoder` input projection only)
- **Approx. wall time:** ~45–70 min per head, sequential → **~2.5–3.5 h
  total**
- **Disk — local committed artifacts:** ~30 MB per head (manifests +
  curves; predictions parquet gitignored)
- **Disk — remote working set:** 3 × ~300 MB checkpoints + ~6 GB
  intermediate (3 × val/test predictions) → **≥ 12 GB free beyond the
  OTM data**
- **Notes:** same Pod tier as 3X.9. Best amortised in the same Pod
  window as 3C.4 (ensemble) to avoid two rentals. OTM benchmark
  (~3 GB) should already be on the Pod volume from 3X — do not
  re-download. If pod was terminated after 3X.14, plan ~10 min to
  re-sync.

## Implementation steps

1. Confirm 3C.2 `done` and on the Pod's checkout of `main`.
2. Clone the three 3X.9 configs; set `data.feature_set: micro_v1`;
   leave all other fields untouched (operator should `diff` against
   the 3X.9 configs and confirm only the feature_set line changes).
3. Set up the GPU pod (or re-attach to the 3X-era pod if still warm).
4. Run gaussian → quantile → point sequentially, each logged with
   `tee` to `runs/3C3/<head>/train.log`.
5. Pull back manifests + curves + per-row val/test predictions to
   local.
6. Verify quantile monotonicity on test; verify finite losses; verify
   prediction row count matches benchmark query row count.
7. Append an entry to `docs/experiments/experiment_journal.md` with
   per-head test MAE, val MAE, NLL, ANP-vs-RBF gap, ANP-vs-3X.9 delta.
8. Run PMR gate dry-run.
9. Flip BOARD row → `in_review`.
