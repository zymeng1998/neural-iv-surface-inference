## Purpose

Implement the **Alpha Vantage `HISTORICAL_OPTIONS`** ingest **locally** — code,
tests, and a small-sample (2–3 dates) end-to-end validation that proves the
field-mapping and writes a tiny Parquet matching the existing pipeline schema.
This story is **entirely local**: no full historical pull, no remote work.
It is the last code milestone of Phase A, after which the full pull and rebuild
move to the remote under stories **2C.7** and **2C.8**.

Source decision is locked: see [ADR 0003](../../decisions/0003_spy_options_data_source_migration.md).
The original Dubach static Parquet was confirmed dead (404 + repos removed);
OptionsDX caps at 2023 and fails recency; QuantConnect starts only in 2012 and
adds a two-dataset merge. Alpha Vantage Standard is the only path that delivers
a single consistent source from 2008 → present. The paid key has been
provisioned and a schema probe confirmed `HISTORICAL_OPTIONS` returns every
field our pipeline requires (20 fields per contract, all values as JSON
strings).

## Verified Alpha Vantage response schema (from the 2026-05-22 probe)

`GET https://www.alphavantage.co/query?function=HISTORICAL_OPTIONS&symbol=SPY&date=YYYY-MM-DD&apikey=<key>`
→ `{endpoint, message, data: [<contract>, ...]}`. Each contract carries 20
string-valued fields:

| AV field | Type after parse | Maps to pipeline column |
|---|---|---|
| `date` | date (YYYY-MM-DD) | `date` |
| `expiration` | date | `expiration` |
| `strike` | float | `strike` |
| `type` | str (`call`/`put`) | `type` |
| `bid`, `ask` | float | `bid`, `ask` |
| `bid_size`, `ask_size` | int | optional (carried) |
| `volume` | int | `volume` |
| `open_interest` | int | `open_interest` |
| `implied_volatility` | float | `implied_volatility` |
| `delta`, `gamma`, `theta`, `vega`, `rho` | float | optional (carried, not consumed by pipeline) |
| `last`, `mark` | float | optional (carried) |
| `contractID`, `symbol` | str | optional (carried) |

Density anchors: 2024-01-05 → 7,618 contracts; 2026-05-15 → 13,796. Coverage
reaches the present trading week.

## Implementation steps

1. **Write the AV ingest tests first** (RED) in `tests/test_alpha_vantage_ingest.py`:
   - mock a `HISTORICAL_OPTIONS` response shaped exactly like the verified
     schema above; assert the parser produces a DataFrame with the correct
     dtypes and `REQUIRED_OPTIONS_COLS` columns;
   - the date-loop iterator skips non-trading days (uses an exchange calendar
     or AV's empty `data` to detect);
   - the rate-limiter enforces ≤75 req/min;
   - retry with exponential backoff on transient failures (HTTP 5xx, network);
   - hard-fail on auth errors (HTTP 401 / "premium endpoint" payload);
   - the API key is read from `os.environ["ALPHAVANTAGE_API_KEY"]` and **never
     written to any file** (test asserts log/output redaction).
2. **Implement `src/data/01_ingest_spy_alpha_vantage.py`** (new script, beside
   the old one for now):
   - paginate per trading day from a config-driven `start_date` → `end_date`
     (defaults: `2008-01-02` → today);
   - one HTTP GET per date, respect the 75/min ceiling;
   - parse each contract to typed Python primitives, accumulate into per-year
     Parquet partitions (streaming write — do **not** keep raw JSON unless an
     explicit `--cache-json` flag is set, off by default);
   - on completion, consolidate per-year partitions → `spy_options.parquet`;
   - keep the underlying via `yfinance` but fix `end` to `datetime.now()`
     (kill the hardcoded `"2026-01-01"`);
   - regenerate `reports/spy_ingest_summary.md` and write
     `data_raw/spy/ingest_metadata.json` with source + date range + row counts.
3. **Update `src/data/config.py`**:
   - add `ALPHAVANTAGE_BASE_URL`, `ALPHAVANTAGE_RATE_LIMIT_PER_MIN = 75`,
     `ALPHAVANTAGE_API_KEY_ENV = "ALPHAVANTAGE_API_KEY"`,
     `INGEST_START_DATE = "2008-01-02"`;
   - leave the old Dubach URL constants in place but comment them
     `# DEFUNCT 2026-05-22 — see ADR 0003`.
4. **Sample validation** (local, small):
   - Run the new ingest with `--dates 2024-01-05 2026-05-15` (two dates only,
     no full pull). Confirm output Parquet has the right columns, dtypes,
     and ~7.6K + ~13.8K rows respectively.
   - Spot-check by passing the tiny Parquet through `02_inspect_spy_schema.py`
     and a one-year-restricted run of `03_build_spy_surface_table.py
     --test-year 2024` to confirm the downstream pipeline accepts the new file
     unchanged.
5. **Record**: update `data_lineage.md` §3 (active source = Alpha Vantage),
   append a progress-log entry, run the PMR gate dry-run, mark this story
   `done`.
