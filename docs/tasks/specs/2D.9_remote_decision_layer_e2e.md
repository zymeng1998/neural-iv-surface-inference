## Purpose

Closing evidence story for epic 2D. Run the decision-layer runner built
locally in **2D.6** against the **real Alpha Vantage benchmark** with the
full predictor lineup:

- interpolation baseline (per-date RBF / griddata),
- Phase-1 masked MLP,
- point conditional (2C),
- calibrated conditional (2D.4) — fuses 2D.7 head + 2D.8 ensemble + 2B.2
  masking sensitivity through the 2D.4 calibrator.

Produce the W1 + W2 + decision-layer artifacts under `results/2D/`, write
the `experiment_journal.md` entry that closes epic 2D acceptance §5
("decision-grade outputs are produced") and §6 ("calibration is
demonstrated"), and pull all artifacts back to the laptop for commit.

## Where this runs

**Remote (RunPod) only.** Requires the AV dataset on disk, the 2C
single-seed checkpoint, the 2D.7 head checkpoints, the 2D.8 ensemble
member checkpoints, and the 2D.4 calibrator JSON. The Pod scores all
predictors at full scale. Pull `results/2D/` back to the laptop; the
artifact commit, journal entry, and live PMR gate run from the laptop.

## Implementation steps

1. On the Pod, materialize `configs/decision_layer_eval_av.yaml` listing
   the AV benchmark + the four predictor entries pointing at the right
   checkpoints / calibrator paths.
2. Run `scripts/run_decision_layer_eval.py --config
   configs/decision_layer_eval_av.yaml --results-root results/2D/`.
3. Per-pair artifacts under `results/2D/<dataset>/<predictor>/`:
   per-row predictions+decisions CSV, metrics summary CSV, region-level
   tradability table, abstention curve PNG, calibration plot PNG.
4. Top-level `results/2D/comparison_summary.csv` with columns:
   `dataset, predictor, test_mae, hi_conf_mae, coverage_90, mean_width,
   abstain_rate, mean_tradability, n_forbidden_flag_violations`.
5. Rsync `results/2D/` back to the laptop. Commit the artifacts.
6. Write the closing `experiment_journal.md` entry citing the runner
   config, all artifact paths, and the two acceptance numbers below.
7. Bump `docs/agent_bootstrap/reviewer_state.{json,md}` (entry count, git
   head, last-processed timestamps).
8. Update `docs/logs/progress_log.md`.
9. Run the live PMR gate.
