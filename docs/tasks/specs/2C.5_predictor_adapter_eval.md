## Purpose

Close the W3 loop by making the conditional model a first-class citizen of the
existing evaluation stack. This story wraps the trained conditional model behind
the model-agnostic `Predictor` interface and runs it through the **same** W1
uncertainty-evaluation runner and W2 structure-diagnostics runner, on the
**same** benchmarks as the Phase 1 baselines — satisfying Phase 2 acceptance
criterion #4 ("a conditional neural surface model ... evaluated on the same
benchmarks as the Phase 1 baselines"). The deliverable is committed result
artifacts plus an experiment-journal entry comparing the conditional model to
the interpolation floor and the MLP, with explicit attention to the regions
where the MLP was weakest (short maturities, deep wings).

## Non-goals

- Do NOT add W4 reliability signals — `ConditionalSurfacePredictor` returns
  `uncertainty=None` like the baselines (uncertainty arrives in epic 2D).
- Do NOT modify the W1/W2 runner internals — the conditional predictor must plug
  into them unchanged. If a runner needs a predictor-selection flag, that is the
  only allowed runner edit.
- Do NOT retrain the model here (use the 2C.4 checkpoint). Full RunPod training +
  full-benchmark eval is a documented follow-up; the local deliverable is the
  synthetic-checkpoint eval proving wiring + artifact shape.
- Do NOT redirect verbose run output into the conversation — log to file, report
  summary numbers only.

## Implementation steps

1. Write the adapter test first (RED): a `ConditionalSurfacePredictor` built from
   a tiny 2C.4 checkpoint, called on a synthetic multi-date frame, returns a
   `PredictionResult` whose `pred` length and order match the input frame.
2. Implement `ConditionalSurfacePredictor.predict(df)`: group `df` by date, build
   each date's context from its `observed == True` rows (2C.2 logic), decode at
   that date's frame rows, and **re-align** outputs to original `df` row order
   (mirror `MLPPredictor`'s non-shuffled alignment guarantee). `uncertainty=None`.
3. Run the W1 uncertainty-eval runner and W2 diagnostics runner with the
   conditional predictor on a synthetic benchmark; write artifacts under
   `artifacts/results/`.
4. Append an experiment-journal entry: metrics for conditional vs interpolation
   vs MLP (MAE overall + observed/unobserved split + short-maturity / wing
   regions), plus structural-violation and masking-stability summaries.
5. Run `pytest tests/ -q`, the smoke test, and the PMR gate. Update progress log
   + roadmap (mark epic 2C `done` once parity is demonstrated).

      returns predictions aligned to input `df` row order (verified by test).
- [ ] The conditional model runs through the **unchanged** W1 and W2 runners and
      produces the same artifact shapes as the baselines.
- [ ] Experiment-journal entry compares conditional vs interpolation floor vs MLP
      (overall + observed/unobserved + short-maturity/wing regions).
- [ ] All tests pass; PMR gate dry-run passes.
- [ ] Phase 2 acceptance criterion #4 is met; epic 2C marked `done` on the board.

## Rollback notes

remove `ConditionalSurfacePredictor` + its test and revert any predictor-flag
edit in the runners; delete the new `artifacts/results/` files; revert doc
touches. No training data mutated; the 2C.4 checkpoint is preserved.
