## Purpose

End-to-end decision-layer eval of the calibrated **ANP + `micro_v1`**
predictor (3C.3 gaussian + 3C.4 ensemble + 3C.5 calibrator) on
`spy_phase1_random40_noiselow_otm`. **Thresholds held constant** with
3X.12 (per the 3X Q2 invariant — no decision-config retune inside
either feature-level study). Ships the headline 3C result bundle and
the journal entry that 3C.7 / 3C.8 consume.

This is the story that adjudicates the Phase 3 accuracy bar for the
`micro_v1` feature set.

## Where this runs

**Remote (RunPod), GPU pod.** Same Pod as 3C.3 / 3C.4 if rented in a
single window. The 2D.6 decision-layer runner needs the checkpoints
(Pod-side) and the OTM benchmark (Pod-side); local mirrors are not
required for the run itself.

## Scope contract (atomic story)

- **One question:** with thresholds held constant against 3X.12, what
  is the calibrated ANP+`micro_v1` test MAE, hi-conf MAE@0.5,
  coverage@0.90, mean band width, abstention rate, and forbidden-flag
  violation count on `random40_noiselow_otm`, and does the model meet
  the Phase 3 acceptance bar (≥ 5 % below RBF-on-OTM 0.00613, coverage
  within ±2 pp of 0.90, hi-conf MAE strictly below no-abstention MAE,
  forbidden-flag violations not meaningfully greater than 3X.12's
  1814)?
- **One artifact bundle:**
  `results/3/spy_phase1_random40_noiselow_otm/3c_anp_micro/` mirroring
  the 3X.12 result schema (per-row test predictions, metrics summary,
  flag-violation breakdown, decision-config snapshot).
- **One acceptance check:** finite metrics; schema parity with 3X.12;
  thresholds-held-constant invariant verified by config-diff; verdict
  (bar met / partial / NOT met) journaled with explicit deltas vs
  3X.12 and vs RBF-on-OTM.
