## Purpose

Build the reproducible generator for the Phase 3 results notebook,
mirroring `scripts/generate_phase2_results_notebook.py` (2D.10). The
script is the single code surface Phase 3D is allowed to touch (per
[`3D.1`](3D.1_decompose_phase_3d.md) non-goals). It programmatically
assembles `notebooks/06_phase3_results.ipynb` from already-committed
Phase 3 bundles so the notebook is regenerable when artifacts change.
This story delivers the **script only**; 3D.4 runs it to emit the
committed `.ipynb`.

## Where this runs

**Local (Mac), CPU-only.** Pure pandas / matplotlib / nbformat over
committed artifacts. No model load, no Pod, no GPU, no data download.

## Scope contract (atomic story)

- **One question:** can the Phase 3 results notebook be reconstructed
  end-to-end from committed bundles by a single script (no manual cell
  authoring, no re-run of any model/eval)?
- **One artifact bundle:** `scripts/generate_phase3_results_notebook.py`
  (+ a small smoke test).
- **One acceptance check:** the script exits 0 and writes a notebook
  whose cells reference only committed paths; running it twice is
  idempotent (byte-stable section structure).
