## Purpose

Close Phase 2 with an **executive-readable narrative** paralleling the Phase
1 / Phase 2C precedents (`docs/phase1_result_memo.md` and
`notebooks/04_phase2c_results.ipynb`). 2D.9 produced the raw metric
collection — committed CSVs, figures, and an internal-style
experiment-journal entry. That is enough for a reviewer, but **not** enough
for a non-author reader to understand what Phase 2 delivered, how the
calibrated reliability-aware system compares to the Phase 1 interpolation
floor and the Phase 2C point conditional, and where the remaining open
questions live.

This story produces:

1. `docs/phase2_result_memo.md` — executive summary, headline numbers,
   acceptance-criteria mapping (§1–§7), what changed vs Phase 1 / 2C.
2. `notebooks/05_phase2_results.ipynb` — interactive walkthrough with
   curated figures and a worked single-date example showing all six
   decision-grade outputs.

Both consume the committed `results/2D/` artifacts from 2D.9 plus the
existing `artifacts/runs/2D7/` and `artifacts/runs/2D8/` predictions.
**No new training, no new evaluation runs.** Pure synthesis and
presentation.

## Where this runs

**Local (Mac) only.** All inputs are already committed to the repo by 2D.9
+ 2D.7 + 2D.8. No Pod time, no model loading, no GPU. Pure pandas /
matplotlib / markdown.

## Implementation steps

1. **Audit the inputs.** From `results/2D/comparison_summary.csv` and the
   per-pair directories under `results/2D/spy_phase1_random40_noiselow/`,
   enumerate which predictors / datasets actually have evidence. Record any
   gaps (e.g. predictors that 100%-abstained on test) as memo open
   questions.
2. **Write `docs/phase2_result_memo.md`** with the following structure:
   - One-paragraph TL;DR: what Phase 2 delivered, headline numbers.
   - Phase 2 scope recap (W1→W2→W3→W4→W5 in one paragraph each).
   - **Headline results table** sourced from
     `results/2D/comparison_summary.csv` (one row per predictor: test MAE,
     coverage at 90%, mean width, hi-conf MAE, abstain rate, mean
     tradability).
   - Calibration evidence: numbers from the journal entry (coverage tolerance
     met / not met, hi-conf MAE strictly less than no-abstain MAE — paths to
     the `calibration_plot.png` figures).
   - What changed vs Phase 1: interpolation floor (MAE 0.0687) → calibrated
     conditional with abstention; explicit before / after.
   - What changed vs Phase 2C: point conditional (MAE 0.0855, no
     uncertainty) → calibrated conditional with `confidence_score`,
     `uncertainty_band`, `abstain_flag`, `tradability_score`.
   - **Acceptance-criteria map**: a checklist mapping §1–§7 of the roadmap
     to artifacts that satisfy each one (paths required).
   - Open questions / known limitations: list every "Open questions" item
     from 2D.4 / 2D.5 / 2D.9 that is still live (e.g. the
     `max_relative_width` retuning question from the 2D.9 handoff). No
     vague language — each item is a concrete next decision.
3. **Build `scripts/generate_phase2_results_notebook.py`** mirroring
   `scripts/generate_phase2c_results_notebook.py` — programmatic
   construction so the notebook is regeneratable when artifacts change.
   Sections:
   - Title + TL;DR cell (mirrors memo).
   - Headline results table (read `comparison_summary.csv`, render).
   - Per-predictor pages: render the committed `calibration_plot.png`,
     `abstention_curve.png`, `region_tradability.csv` for each predictor
     by path. Reference, do not regenerate.
   - Worked single-date example: pick one date from
     `results/2D/spy_phase1_random40_noiselow/conditional_calibrated/`,
     load that date's slice of the per-row predictions+decisions CSV,
     show all six decision-grade outputs `(sigma_hat, confidence_score,
     lower, upper, no_arb_risk_flags, abstain_flag, tradability_score,
     decision_reason)` over a (k, τ) grid; one heatmap per output.
   - Training dynamics: per-head and per-ensemble-member curves from
     `artifacts/runs/2D7/<head_kind>/training_curve.csv` and
     `artifacts/runs/2D8/training_curves.csv`.
   - Acceptance-criteria map cell (mirrors memo).
   - Open-questions cell.
4. Generate the notebook: `python3
   scripts/generate_phase2_results_notebook.py`. Verify it executes top to
   bottom with no errors and 0 cell errors.
5. Update `docs/logs/progress_log.md`.
6. Flip epic 2D to `in_progress` on the BOARD (reopened by this story);
   add a 2D.10 row at `backlog`.
7. Run the live PMR gate (this commit touches `docs/phase2_result_memo.md`
   which is evidence-class).
