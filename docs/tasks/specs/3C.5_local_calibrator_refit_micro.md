## Purpose

Re-fit the Phase 2D calibrator on **ANP + `micro_v1`** val predictions
(3C.3 gaussian / quantile + 3C.4 ensemble disagreement) to produce
`artifacts/calibration/3C5_anp_micro.json`, the calibrator the
production decision-layer predictor will use in 3C.6.

Mirrors 3X.11 (which mirrored 3B.6 / 2D.4) — no code change to the
calibration recipe; only the input prediction files change.

## Where this runs

**Local (Mac), CPU-only.** Reads the val parquet pulled back by 3C.3
and 3C.4; writes a small JSON.

## Scope contract (atomic story)

- **One question:** what temperature `T` and `ensemble_scale` does the
  Phase 2D recipe fit on the ANP+`micro_v1` val predictions, and does
  the resulting calibrator achieve val coverage@0.90 within ±2 pp and
  val hi-conf MAE strictly below val no-abstention MAE?
- **One artifact bundle:** `configs/calibration_3C5_anp_micro.yaml` +
  `artifacts/calibration/3C5_anp_micro.json` +
  `tests/test_calibration_anp_micro.py`.
- **One acceptance check:** val coverage@0.90 within ±2 pp of 0.90;
  val hi-conf MAE@0.5 < val no-abstention MAE; JSON schema parity with
  3X.11 / 3B.6 / 2D.4.

## Implementation steps

1. Verify the four val prediction parquet files exist locally.
2. Clone `configs/calibration_3X11_anp_otm.yaml` →
   `configs/calibration_3C5_anp_micro.yaml`; re-point input paths.
3. Run the calibration script (existing
   `scripts/fit_calibrator.py` from 2D.4 / 3B.6 / 3X.11 — no
   modification) → produces `artifacts/calibration/3C5_anp_micro.json`.
4. Inspect the JSON — record `T`, `ensemble_scale`, val cov@0.90, val
   hi-conf MAE in the journal.
5. Write `tests/test_calibration_anp_micro.py` mirroring the 3X.11 /
   3B.6 test files.
6. `pytest tests/test_calibration_anp_micro.py -v` — all green.
7. PMR gate dry-run; flip BOARD → `in_review`.
